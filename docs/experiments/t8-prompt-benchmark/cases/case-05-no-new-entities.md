# Case 05: No New Entities

## 上文摘要

目前已出现的人物只有林澈、沈知夏、追兵小队。已出现组织只有灰塔实验室和旧港站管理处。故事当前重点是两人躲避追兵并确认银色芯片来源。

## 必须保持的事实

- 本场只能使用林澈、沈知夏、追兵小队。
- 本场只能提及灰塔实验室和旧港站管理处。
- 不能引入新的导师、神秘老人、黑客盟友、隐藏组织。

## 禁止改变的事实

- 不能新增人物。
- 不能新增组织。
- 不能新增超自然能力或系统设定。

## 本场生成目标

林澈和沈知夏利用旧港站管理处留下的广播设备误导追兵小队，为下一场进入月台控制室争取时间。

## 预期风险点

- 小模型喜欢新增神秘人物帮助主角。
- 新组织突然出现。
- 风格滑向爽文开挂。

## 评价指标

重点看禁止事项遵守、场景目标完成、风格稳定。
