四条初期管线

管线 用途 步骤
generate 生成章节 draft → review → fix → polish
polish 润色已有内容 draft → review → fix
rewrite 重写 draft → review → fix → polish
extract 信息提取 extract → validate → format

流式策略

前端零感知：中间步骤静默运行，只发 thinking 事件告知状态

发往前端

  • thinking — "正在生成初稿..."
  • thinking — "正在检查一致性..."
  • generation — 最终内容（流式）
  • done — 完成

后台静默

  • draft 阶段原始输出
  • self_review 的检查结果
  • fix 阶段中间内容
  • 任何失败/重试

配置

每条管线一个 YAML 文件，存储在 workspace/prompts/pipeline/

# workspace/prompts/pipeline/generate.yaml
steps:
  - name: draft
    prompt: pipeline/generate/draft
    fallback: null

  - name: self_review
    prompt: pipeline/generate/self_review
    fallback: draft_text

  - name: fix
    prompt: pipeline/generate/fix
    fallback: draft_text

  - name: polish
    prompt: pipeline/generate/polish
    fallback: prev_text
