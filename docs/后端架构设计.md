# 墨韵 - 后端架构设计文档

## 一、概述

本文档定义墨韵后端的核心架构，包括目录结构、模块划分、数据模型和API路由。

> **编码规范**：请参考 [编码规范.md](./编码规范.md)

**依赖技术**：
- FastAPI - Web框架
- LiteLLM - LLM统一调用
- aiofiles - 异步文件操作
- python-frontmatter - Markdown元数据
- Jinja2 - Prompt模板渲染
- tiktoken - Token计数
- watchdog - 文件监听
- tenacity - 重试机制

| `models/*` | 数据结构定义 | 浅层 |
| `schemas/*` | API请求/响应 Pydantic 模型 | 浅层 |

### 3.3 架构优化要点

#### 删除测试（Deletion Test）
- **EventBus**: 删除后，所有模块的事件发布逻辑需要重写 → 深层 ✓
- **PipelineRunner**: 删除后，多步LLM编排逻辑分散到API层 → 深层 ✓
- **PromptEngine**: 删除后，模板渲染逻辑需要重写 → 深层 ✓
- **snapshot.py**: 删除后，快照功能消失但不影响核心 → 浅层

#### 关键深化机会
1. **抽象 Service 接口层**：可通过新增 `services/` 层解耦 API 与 Core（当前部分 API 路由含较多业务逻辑）
2. **PromptEngine→FileService**：依赖注入解耦
3. **TaskQueue职责分离**：状态管理 vs 执行逻辑
4. **FileWatcher→EventBus**：监听 vs 事件分发
5. **异常体系集中**：core/exceptions.py 统一处理

### 4.4 任务队列（core/task_queue.py）

实际代码将队列状态管理与执行逻辑分离为两个类：

```python
class TaskQueue:
    """任务队列（仅状态管理）"""

    def __init__(self):
        self._tasks: dict[str, dict] = {}
        self._queue: asyncio.Queue = asyncio.Queue()
        self._running: set[str] = set()
        self._executor: TaskExecutor | None = None

    async def enqueue(self, task_data: dict) -> str:
        """添加任务到队列，返回 task_id"""

    async def dequeue(self) -> str | None:
        """从队列取任务 ID"""

    def start_task(self, task_id: str) -> None:
        """标记任务为运行中"""

    def complete_task(self, task_id: str, result: Any) -> None:
        """标记任务完成"""

    def fail_task(self, task_id: str, error: str) -> None:
        """标记任务失败"""

    def cancel_task(self, task_id: str) -> None:
        """取消任务"""

class TaskExecutor:
    """任务执行器"""

    def __init__(self, llm_service, file_service, event_bus):
        self.llm = llm_service
        self.file_service = file_service
        self.event_bus = event_bus

    async def execute_task(self, task: dict) -> dict:
        """执行单个任务（调用 PromptEngine + LLM）"""
```

### 4.5 EventBus 与 文件监听（core/event_bus.py, core/watcher.py）

```python
class EventBus:
    """事件总线（发布/订阅模式）"""

    def __init__(self):
        self._subscribers: list[asyncio.Queue] = []

    async def publish(self, event_type: str, data: dict) -> None:
        """发布事件到所有订阅者"""

    def subscribe(self) -> tuple[str, asyncio.Queue]:
        """订阅事件，返回 (id, queue)"""

    def unsubscribe(self, queue: asyncio.Queue) -> None:
        """取消订阅"""

class FileWatcher:
    """文件监听器，通过 watchdog 监听文件变化并发布到 EventBus"""

    def __init__(self, projects_path: Path, event_bus: EventBus):
        self.projects_path = projects_path
        self.event_bus = event_bus
        self.observer: Observer | None = None

    def start(self) -> None:
        """启动监听（同步方法）"""

    def stop(self) -> None:
        """停止监听（同步方法）"""

    def on_any_event(self, event: FileSystemEvent) -> None:
        """处理文件事件并发布到 EventBus"""
```

**事件流**：`watchdog 检测文件变化 → FileWatcher.on_any_event() → EventBus.publish() → SSE bridge → SSE endpoint → 前端`

### 6.2 PromptEngine 与 PipelineRunner

**PromptEngine**（旧模板系统，`core/prompt_engine.py`）：
```python
class PromptEngine:
    """Prompt模板引擎（旧系统，generate.chapter 等模板使用）"""

    def __init__(self, prompts_path: Path, file_service: FileService):
        self.prompts_path = prompts_path
        self.file_service = file_service
        self.env = Environment(loader=FileSystemLoader(str(prompts_path)))

    async def render(self, prompt_type: str, variables: dict) -> str:
        """渲染模板，路径格式：{prompt_type}/main.md"""
        template = self.env.get_template(f"{prompt_type}/main.md")
        return template.render(**variables)
```

**PipelineRunner**（管线系统，`core/pipeline.py`）：
```python
class PipelineRunner:
    """管线执行引擎（多步骤 LLM 调用）"""

    def __init__(self, prompts_path: Path, llm_service: LLMService, file_service: FileService):
        self.prompts_path = prompts_path
        self.llm_service = llm_service
        self.file_service = file_service
        self.env = Environment(loader=FileSystemLoader(str(prompts_path)))

    def load_pipeline(self, name: str) -> PipelineDef:
        """加载管线 YAML 定义"""

    async def run(
        self,
        pipeline_name: str,
        project_id: str,
        target_file: str | None = None,
        user_input: str | None = None,
        output_mode: str = "overwrite",
        extra_vars: dict | None = None,
        stop_event: asyncio.Event | None = None,
        llm_extra_kwargs: dict | None = None,
    ) -> AsyncGenerator[dict, None]:
        """执行管线，按步骤依次调用 LLM"""
```

**区别**：
| 特性 | PromptEngine（旧） | PipelineRunner（管线） |
|------|-------------------|----------------------|
| 模板格式 | `{category}/{type}/main.md` | `pipeline/{name}.yaml` + `{step_id}.md` |
| 步骤 | 单步 | 多步（支持 fallback） |
| 变量注入 | 手动传入 | 自动加载系统/章节变量 |
| 输出控制 | 直接 LLM 输出 | 按 output_mode 写入文件 |
| 后处理 | 无 | 自动更新 story-state/recent-context/revision-log |

## 八、启动流程

```python
# main.py（实际启动流程，使用 lifespan 上下文管理器）
from contextlib import asynccontextmanager

from backend.config import get_settings
from backend.core.event_bus import EventBus
from backend.core.llm import LLMService, load_llm_config_from_workspace
from backend.core.file_ops import FileService
from backend.core.task_queue import TaskQueue, run_task_worker
from backend.core.watcher import FileWatcher
from backend.api.sse import sse_manager

@asynccontextmanager
async def lifespan(app: FastAPI):
    """启动 / 关闭钩子"""
    settings = get_settings()

    # 初始化 EventBus 并挂载到 app.state
    event_bus = EventBus()
    app.state.event_bus = event_bus

    # 初始化 SSE Manager
    app.state.sse_manager = sse_manager

    # 启动 EventBus → SSE 桥接任务
    sse_bridge_task = asyncio.create_task(_bridge_events_to_sse(event_bus, sse_manager))
    app.state.sse_bridge_task = sse_bridge_task

    # 初始化文件监听器（watchdog → EventBus）
    if settings.projects_path.exists():
        watcher = FileWatcher(settings.projects_path, event_bus)
        watcher.start()

    # 初始化任务队列和工作线程
    task_queue = TaskQueue()
    llm_service = LLMService.from_workspace_config(...)
    file_service = FileService(settings.projects_path)
    worker_task = asyncio.create_task(
        run_task_worker(task_queue, llm_service, file_service, event_bus)
    )

    yield  # 应用运行中

    # 关闭时清理
    sse_bridge_task.cancel()
    worker_task.cancel()
    watcher.stop()

app = FastAPI(title="墨韵 API", version="0.1.0", lifespan=lifespan)

# 注册路由（23 个 router）
# ...

@app.get("/health")
async def health():
    return {"status": "ok"}
```

**SSE 桥接**：EventBus 事件通过 `_bridge_events_to_sse()` 协程桥接到 SSE Manager，事件类型中的 `:` 自动替换为 `-`（如 `file:created` → `file-created`）。

### 9.1 自定义异常
```python
class MoyunException(Exception):
    """墨韵应用异常基类（code 用于 HTTP 状态码映射）"""
    def __init__(self, message: str, code: str, details: Any = None):
        self.message = message
        self.code = code
        self.details = details

class ProjectNotFoundError(MoyunException):
    """项目不存在（code: PROJECT_NOT_FOUND → 404）"""

class FileNotFoundError(MoyunException):
    """文件不存在（code: FILE_NOT_FOUND → 404）"""

class TemplateNotFoundError(MoyunException):
    """模板不存在（code: TEMPLATE_NOT_FOUND → 404）"""

class LLMError(MoyunException):
    """LLM调用错误（code: LLM_ERROR → 503）"""

class ValidationError(MoyunException):
    """数据验证失败（code: VALIDATION_ERROR → 422）"""
```
完整异常体系见 `backend/core/exceptions.py`（含 ContextLengthError、RateLimitError、ResourceNotFoundError 等衍生类）

### 9.2 全局异常处理

```python
from fastapi import Request
from fastapi.responses import JSONResponse

    return JSONResponse(
        status_code=400,
        content=error_response(
            message=exc.message,
            code=exc.code,
            details=exc.details
        )

@app.exception_handler(Exception)
```
