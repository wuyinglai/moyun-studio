# API 文档拆分入口

当前权威 API 契约仍是 [../API契约.md](../API契约.md)。本目录用于后续把过大的 API 契约拆成模块文档。

## 计划拆分

| 未来文件 | 内容边界 |
| --- | --- |
| `project.md` | 项目创建、打开、列表、元数据 |
| `files.md` | 文件树、读写、保存、删除、快照、回收站 |
| `lite.md` | 爽文模式、开局卡、爽点卡、流式生成、候选稿 |
| `workflow.md` | 工作流运行、暂停恢复、节点状态、变量池 |
| `prompt.md` | Prompt 模板、管线、参数、模型配置 |
| `memory.md` | 故事引擎、近期上下文、角色状态、质量摘要 |

## 使用规则

- 拆分前，继续以 `../API契约.md` 为准。
- 拆分时每个接口要包含请求、响应、错误码、SSE 事件和前端调用方。
- 拆分完成后，`../API契约.md` 应变成总览和模块目录。
