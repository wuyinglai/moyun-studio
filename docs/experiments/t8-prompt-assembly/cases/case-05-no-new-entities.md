# Case 05: No New Entities

## 上文摘要

目前已出现的人物只有林澈、沈知夏、追兵小队。已出现组织只有灰塔实验室和旧港站管理处。故事当前重点是两人躲避追兵并确认银色芯片来源。

## 事实块

- 人物状态：林澈和沈知夏正被追兵小队逼近。
- 道具归属：可使用旧港站管理处留下的广播设备。
- 地点限制：旧港站管理处或其广播设备所在区域。
- 时间线：当前目标是为进入月台控制室争取时间。
- 允许实体：林澈、沈知夏、追兵小队、灰塔实验室、旧港站管理处。

## 禁止改变项

- 不能新增人物。
- 不能新增组织。
- 不能新增导师、神秘老人、黑客盟友、隐藏组织。
- 不能新增超自然能力或系统设定。

## 本场目标

林澈和沈知夏利用旧港站管理处留下的广播设备误导追兵小队，为下一场进入月台控制室争取时间。

## 预期风险点

- 小模型喜欢新增神秘人物帮助主角。
- 新组织突然出现。
- 风格滑向爽文开挂。

## 评价指标

重点看禁止事项遵守、场景目标完成、风格稳定。
