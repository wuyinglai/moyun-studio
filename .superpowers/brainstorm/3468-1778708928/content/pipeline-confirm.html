管线引擎 — 设计确认

已经确定的部分

✅ 架构

  • PipelineRunner 独立模块 core/pipeline.py
  • 每条管线一个 YAML 配置，定义步骤
  • 每步独立的 Prompt 模板
  • 失败容忍：某步挂了 fallback 到上一步

✅ 流式策略

  • 中间步骤：静默运行，只发 thinking 事件
  • 最终步骤：正常流式输出
  • 前端零感知

✅ 四条管线

管线 步骤
polish 去AI味 → 提升文笔 → 修逻辑漏洞 → 优化节奏
generate 整合上下文 → 大纲对齐 → 写作初稿 → 去AI味 → 逻辑修正 → 节奏优化
rewrite 诊断问题 → 重写初稿 → 去AI味 → 逻辑修正 → 节奏调整
extract 每轮一个维度：角色+关系 → 情节+场景 → 世界观 → 摘要
