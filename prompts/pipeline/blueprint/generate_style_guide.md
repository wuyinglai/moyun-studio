# 生成文风指南

你是一名资深文学编辑。请根据以下项目信息，生成一份文风指南。

## 项目信息
- **题材**：{{ genre }}
- **核心主题**：{{ theme }}
- **作品基调**：{{ tone }}
- **写作风格**：{{ writing_style }}

## 要求
请按以下结构输出完整的文风指南（Markdown 格式），直接输出不要添加说明：

### 一、文风定位
- 整体风格：根据题材和基调确定
- 句子节奏：长短句搭配方式
- 描写密度：场景/心理/对话的比例
- 语言特点：用词偏好、修辞风格

### 二、写作风格要点
- 叙述方式（如第三人称有限视角）
- 对话风格（如自然口语化）
- 心理描写（如适度、点到即止）
- 场景描写（如注重氛围烘托）

### 三、写作禁忌
- 针对本题材应避免的表达方式

### 四、题材特点
- 本题材特有的表达习惯和术语规范
