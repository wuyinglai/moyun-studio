# v0.2.2 Release Notes

## 版本定位

**v0.2.2** 是 v0.2 系列的维护版（maintenance release），不包含新功能开发。

- 清理 guardrails 安全检查噪声
- 整理 T9.4 阶段文档状态
- 更新 known issues 和 roadmap

## 已解决

### v0.2.2a — Guardrails Allowlist Cleanup

- **问题**：`ai-guardrails.ps1` 报告大量 violation，但实际无真实安全风险
- **解决**：所有 violation 分类为 B/D/C 类（测试噪声、历史兼容、文档说明），添加 `AI_GUARDRAIL_ALLOW` 注释
- **结果**：Guardrails PASS，无 remaining noise
- **报告**：`docs/security/v0-2-2a-guardrails-allowlist-cleanup.md`

### v0.2.2b — Docs Consolidation + Known Issues Update

- **问题**：T9.4 阶段文档状态分散，known issues 未更新 v0.2.1/v0.2.2a 解决项
- **解决**：
  - 更新 `docs/known-issues.md` — 新增 Version Status + Recently Resolved
  - 更新 `docs/roadmap.md` — 标记 v0.2.2a/v0.2.2b 为 done
  - 更新 `docs/roadmaps/t10-v0-2-2-scope-decision.md` — 补充状态
- **结果**：文档状态清晰，known issues 包含 R1-R4 已解决项
- **报告**：`docs/roadmaps/v0-2-2b-docs-known-issues-update.md`
