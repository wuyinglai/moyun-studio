## M01 顶部工具栏

**布局说明**：
- **左侧**：Logo（M0101） + 项目名称（M0102）
- **中间**：通知区域（M06）
- **右侧**：LLM状态（M0103）→ LLM调用中（M0104）→ Thinking（M0107）→ 按钮（M0108/M0109/M0110）

### M0101 Logo区域
- 墨韵图标 + 文字

### M0102 项目名称
- 显示当前打开的项目名
- 可编辑
- 项目名称只是展示用，允许重名
- 实际项目通过文件夹名（时间戳/UUID）区分

### M0103 LLM连接状态
- 状态点 + 文字（"已连接" / "未连接"）
- 可点击打开设置
- 位置：顶部工具栏右侧
- SSE事件 `llm-status` 变化时实时更新

### M0104 LLM调用中状态
- 调用时显示动画
- 位置：顶部工具栏右侧，与M0103相邻

### M0107 Thinking开关
- 显示开关样式（开/关状态）
- 位置：顶部工具栏右侧，M0104后面

### M0108 打开项目按钮
- 次要按钮
- 位置：顶部工具栏右侧
- 有项目打开时，先弹出确认对话框
- 点击后打开"打开项目"模态框（M0502）

### M0109 新建项目按钮
- 主要按钮，蓝色高亮

## M02 左侧文件树

### M0201 标题栏
- 显示"文件"
- 刷新按钮
- 调用 `/api/tree` 获取最新文件树

### M0202 文件夹
- 支持展开/折叠
- 图标区分
- 文件夹用途：
  - `chapters/` - 章节文件（卷/章/节三级结构）
    - `vol-{序号}/` - 卷目录
      - `vol-meta.json` - 卷元数据
      - `ch-{序号}/` - 章目录
        - `ch-meta.json` - 章元数据（含memory）
        - `sec-{序号}.md` - 节内容文件
        - `feedback/` - 用户反馈目录（新增）
        - `revision-log/` - 修改日志目录（新增）
  - `characters/` - 角色档案（JSON格式）
    - `{角色ID}.json` - 角色档案
  - `materials/extracted/` - 提取的信息
    - `plots/` - 情节提取
    - `scenes/` - 场景提取
    - `summaries/` - 摘要提取
    - `worldbuilding.md` - 世界观提取（新增）
    - `{自定义类型}/` - 用户自定义提取类型
  - `backup/` - 版本快照
  - 根目录文件（新增）：
    - `style-guide.md` - 文风指南
    - `story-state.md` - 故事全局状态
    - `recent-context.md` - 近期上下文摘要

### M0203 文件项
- 点击打开
- 文件类型图标
- 调用 `/api/file?path={filepath}` 获取文件内容

### M0204 项目结构
```
projects/{项目名}/
├── meta.json               # 项目配置
├── context.json            # 上下文统计
├── outline.md              # 大纲文件
├── style-guide.md         # 文风指南（新增）
├── story-state.md          # 故事全局状态（新增）
├── recent-context.md       # 近期上下文摘要（新增）
├── backup/                # 项目快照目录
├── chapters/              # 章节目录
│   ├── vol-01/           # 卷目录
│   │   ├── vol-meta.json # 卷元数据
│   │   ├── ch-001/       # 章目录
│   │   │   ├── ch-meta.json  # 章元数据
│   │   │   ├── sec-001.md   # 节内容
│   │   │   ├── sec-002.md
│   │   │   ├── sec-003.md
│   │   │   ├── sec-004.md
│   │   │   ├── feedback/      # 用户反馈目录（新增）
│   │   │   │   └── {feedback_id}.json
│   │   │   └── revision-log/   # 修改日志目录（新增）
│   │   │       └── {revision_id}.json
│   │   └── ch-002/
│   └── vol-02/
├── characters/            # 角色档案目录
│   └── {角色ID}.json    # 角色档案
└── materials/            # 素材库目录
    └── extracted/        # 提取结果目录
        ├── worldbuilding.md # 世界观提取（新增）
        ├── plots/        # 情节提取
        │   └── {情节ID}.json
        ├── scenes/       # 场景提取
        │   └── {场景ID}.json
        ├── summaries/    # 摘要提取
        │   └── {章节ID}_{序号}.md
        └── **用户自定义**/    # 用户自定义提取类型
            └── {自定义ID}.json
```

**序号规则**：
- 卷：`vol-01`, `vol-02`, ...（每卷重置）
- 章：`ch-001`, `ch-002`, ...（全局连续）
- 节：`sec-001`, `sec-002`, ...（全局连续，每章固定4节）

### M0205 空状态
- 未打开项目时显示"选择或创建项目"

- 步骤1：生成书名+创意
- 步骤2：生成章节大纲（含卷/章/节结构）

- 根据作品规模计算总节数：总字数 / 1800（每节约1800字）

- 空文件不计入完成数

## SSE 事件类型

| 事件 | 触发时机 | 处理逻辑 |
|------|----------|----------|
| `generation` | AI生成内容 | 编辑器内逐字/逐段显示 |
| `file-created` | 新文件创建 | 刷新文件树 |
| `file-updated` | 文件更新 | 更新编辑器内容 |
| `file-renamed` | 文件被重命名 | 刷新文件树，更新打开的标签页路径 |
| `directory-created` | 目录被创建 | 刷新文件树 |
| `task` | 任务状态变化 | 更新任务卡片 |
| `queue` | 队列变化 | 刷新堆栈列表 |
| `llm-status` | LLM状态变化 | 更新状态灯 |
| `thinking` | AI思考中 | 显示"AI正在思考..." |
| `error` | 错误 | 显示错误横幅 |
| `done` | 任务完成 | 停止加载动画，显示完成提示 |

## 文件格式规范

### Markdown 文件（.md)
所有需要用户阅读和修改的内容都使用Markdown格式：
- 章节内容：`sec-{序号}.md`
- Prompt内容：`main.md`
- 大纲：`outline.md`
- 摘要：`{章节ID}_{序号}.md`
- 片段文件：`blocks/*.md`
- 文风指南：`style-guide.md`（新增）
- 故事状态：`story-state.md`（新增）
- 近期上下文：`recent-context.md`（新增）

### JSON 文件（.json)
结构化数据使用JSON格式：
- 项目配置：`meta.json`
- 上下文统计：`context.json`
- 卷元数据：`vol-meta.json`
- 章元数据：`ch-meta.json`（含memory、story_state、pending_foreshadowing、active_quests）
- 角色档案：`{角色ID}.json`
- 提取结果：`{类型ID}.json`
- Prompt元数据：`meta.json`
- 用户反馈：`{feedback_id}.json`（新增）
- 修改日志：`{revision_id}.json`（新增）

### 章节文件存储规则
- 路径：`chapters/vol-{卷序号}/ch-{章序号}/sec-{节序号}.md`
- 命名：`sec-001.md`、`sec-002.md`...（全局连续）
- 每章固定4节
- 文件内可添加注释：`<!-- 第一卷第一章第一节 -->`

### 角色档案存储规则
- 路径：`characters/{角色ID}.json`
- 角色ID：英文小写 + 下划线（如 `zhang_san`）

### 提取结果存储规则
- 路径：`materials/extracted/{类型}/{ID}.json`
- 摘要类型：`materials/extracted/summaries/{章节ID}_{序号}.md`
- 世界观：`materials/extracted/worldbuilding.md`（新增）

### Prompt模板存储规则
- 路径：`prompts/{分类}/{类型}/`
- 必选：`main.md`（模板内容）
- 可选：`meta.json`（变量定义）、`blocks/`（可复用片段）
- 引用语法：Jinja2 `{% include 'blocks/xxx.md' %}`

## 新增功能模块

### G0120 文风指南管理
- 加载和编辑 `style-guide.md`
