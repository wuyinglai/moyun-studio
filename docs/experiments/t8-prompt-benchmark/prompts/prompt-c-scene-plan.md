你的首要任务是避免逻辑矛盾。

{{goal}}

## 预期风险点
{{risks}}

请输出一个简短场景计划，必须包含：

1. 场景开始状态
2. 本场人物目标
3. 允许出现的人物、地点、道具
4. 禁止触碰的错误
5. 本场推进动作
6. 结尾承接点

不要写正文。

## C2: Draft From Plan Prompt

你是一名长篇悬疑小说作者。请严格根据“场景计划”写下一场景正文。

硬规则：
- 场景计划中的人物、地点、道具、时间线、禁令不得改变。
- 不得新增未在计划中允许的人物、组织、能力或关键设定。
- 如果计划要求伏笔延续，不得提前揭晓全部真相。
- 只输出正文，不输出计划或解释。
