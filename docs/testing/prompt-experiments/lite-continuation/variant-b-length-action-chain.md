# Variant B：字数 + 三段行动链

## 目标

在字数约束基础上，提高场景结构稳定性，避免空泛描写和纯心理活动。

## Prompt Patch

```
本场正文结构要求：

- 目标长度：1000-1500 字；
- 最低不得少于 900 字；
- 至少包含 3 个行动段落；
- 第 1 个行动段落：角色主动采取行动；
- 第 2 个行动段落：外部阻力出现或冲突升级；
- 第 3 个行动段落：角色做出选择、付出代价或获得新信息；
- 不要只写心理活动；
- 不要只写环境描写；
- 每个行动段落都必须推动情节变化。
```

## 预期改善

1. 增强人物行动
2. 减少空泛描写
3. 提高连续生成可接续性
4. 让每场更像"事件"而不是"说明"

## 潜在风险

1. 场景结构可能变得机械
2. 文本可能显得刻意
3. 情绪铺垫场景可能不够自然

## 适用判断

如果 Variant B 的结构明显优于 Variant A，但文本显得套路化，后续应弱化"第 1 / 第 2 / 第 3"式硬序号描述。
