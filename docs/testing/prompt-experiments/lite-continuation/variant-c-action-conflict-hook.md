# Variant C：字数 + 行动链 + 冲突推进 + 结尾钩子

## 目标

这是推荐优先测试的版本，平衡质量提升和 Prompt 复杂度。

## Prompt Patch

```
本场正文生成要求：

一、长度要求
- 目标长度：1000-1500 字；
- 最低不得少于 900 字；
- 至少 6 个自然段；
- 不要用摘要代替正文。

二、行动链要求
- 至少包含 3 个行动段落；
- 每个行动段落都要有明确的角色行动；
- 行动必须带来新的信息、风险、冲突或选择。

三、冲突推进要求
本场必须让以下至少一项发生变化：
- 主角处境更危险；
- 目标更明确；
- 敌对方行动升级；
- 关键资源发生变化；
- 人物关系发生变化；
- 新信息出现。

四、结尾钩子要求
- 结尾不要完全收束；
- 结尾必须留下下一场可继续推进的问题、威胁、选择或行动；
- 不要用"他不知道的是……"这类套路句；
- 钩子应自然来自本场冲突。

五、禁止事项
- 不要输出大纲；
- 不要输出摘要；
- 不要输出系统说明；
- 不要出现"最近5章摘要""系统自动维护""占位""TODO"或模板占位符。
```

## 预期改善

1. 降低 too_short
2. 提升冲突推进
3. 提高下一场可接续性
4. 降低模板泄漏风险
5. 保持比 Variant D 更自然的生成风格

## 潜在风险

1. Prompt 较长
2. 可能增加模型执行成本
3. 部分题材可能需要调整"冲突推进"的定义
4. 某些慢节奏题材可能感觉推进过快

## 推荐结论

优先用 Variant C 做第一轮实验。
