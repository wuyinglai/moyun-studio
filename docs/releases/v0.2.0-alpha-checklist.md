# v0.2.0-alpha Release Checklist

## Preflight

- [ ] `git status --short` is clean.
- [ ] Current branch is `main`.
- [ ] Frontend build passes.
- [ ] Backend tests pass.
- [ ] No API key or secret is committed.
- [ ] Release notes are prepared.
- [ ] Known issues are updated.
- [ ] README alpha status is checked.

## Smoke

- [ ] Create project.
- [ ] Open project.
- [ ] `write_next_scene` creates a candidate when the target scene already has content.
- [ ] `write_next_scene` action label is `continue` / `续写`.
- [ ] Candidate preview does not write body text.
- [ ] Candidate adopt requires confirmation.
- [ ] Unsaved edits warning appears before adopt.
- [ ] Candidate delete does not affect formal body text.
- [ ] Continuity warning is visible.
- [ ] Generation warning persists while relevant.
- [ ] Real LLM smoke passes.
- [ ] FILE_CONFLICT still works.

## Release

- [ ] Tag `v0.2.0-alpha` has not been created yet.
- [ ] GitHub Release `v0.2.0-alpha` has not been created yet.
- [ ] User approval is required before tag/release.

## Suggested Manual Commands Before Publishing

```powershell
git status --short
git diff --check
cd frontend
npm run build
cd ..
python -m pytest backend/tests/test_pipeline.py -v
powershell -ExecutionPolicy Bypass -File scripts/release-preflight.ps1 -Version v0.2.0-alpha
```

Do not create the tag or GitHub Release until the release owner explicitly approves.
