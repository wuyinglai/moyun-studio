# 墨韵 - AI小说创作助手 功能清单

## 文档说明

本文档描述每个模块的功能执行逻辑，与原型生成说明中的模块编号一一对应。

---

## M01 顶部工具栏

### M0101 Logo区域
**功能**：展示产品Logo和名称
- 无交互功能

### M0102 项目名称
**功能**：显示当前打开的项目名，可编辑

**执行逻辑**：
1. 打开项目时更新显示
2. 关闭项目时显示为空或"未打开项目"
3. 项目名称只是展示用，允许重名
4. 实际项目通过文件夹名（时间戳/UUID）区分

### M0103 LLM连接状态
**功能**：显示LLM连接状态，点击打开设置
**位置**：顶部工具栏右侧

**执行逻辑**：
1. 页面加载时，自动检测LLM连接状态
2. 通过 `/api/llm/config` 获取配置，测试连接
3. 连接成功：显示绿色状态点 + "已连接"
4. 连接失败：显示红色状态点 + "未连接"
5. 点击状态区域，打开设置模态框（M0503）
6. SSE事件 `llm-status` 变化时，实时更新状态

### M0104 LLM调用中状态
**功能**：显示LLM正在调用的状态
**位置**：顶部工具栏右侧，与M0103相邻

**执行逻辑**：
1. 监测SSE事件 `generation`、`thinking`
2. 事件开始：显示加载动画 + 当前操作名称（如"正在生成第一章..."）
3. 事件结束：隐藏动画和文字

### M0107 Thinking开关
**功能**：全局开关，控制AI是否启用思考模式
**位置**：顶部工具栏右侧，M0104后面

**执行逻辑**：
1. 显示开关样式（开/关状态）
2. 点击切换状态
3. 保存到配置文件
4. 后续所有LLM请求携带Thinking配置

### M0108 打开项目按钮
**功能**：打开已有项目
**位置**：顶部工具栏右侧

**执行逻辑**：
1. 有项目打开时，弹出确认对话框（是否保存当前项目）
2. 点击按钮，打开"打开项目"模态框（M0502）

### M0109 新建项目按钮
**功能**：创建新项目
**位置**：顶部工具栏右侧，M0108后面

**执行逻辑**：
1. 有项目打开时，弹出确认对话框（是否保存当前项目）
2. 点击按钮，打开"新建项目"模态框（M0501）

### M0110 设置按钮
**功能**：打开系统设置
**位置**：工具栏最右侧

**执行逻辑**：
1. 点击按钮，打开"设置"模态框（M0503）

## M02 左侧文件树

### M0201 标题栏
**功能**：文件树标题和刷新按钮

**执行逻辑**：
1. 显示"文件"
2. 点击刷新按钮，调用 `/api/tree` 获取最新文件树
3. 更新文件树显示

### M0202 文件夹
**功能**：显示项目目录结构，支持展开/折叠

**执行逻辑**：
1. 点击文件夹，切换展开/折叠状态
2. 展开时显示子文件和子文件夹
3. 折叠时隐藏子项

**文件夹说明**：
- `chapters/` - 章节文件（卷/章/节三级结构）
  - `vol-{序号}/` - 卷目录
    - `vol-meta.json` - 卷元数据
    - `ch-{序号}/` - 章目录
      - `ch-meta.json` - 章元数据（含memory）
      - `sec-{序号}.md` - 节内容文件
      - `feedback/` - 用户反馈目录（新增）
      - `revision-log/` - 修改日志目录（新增）
- `characters/` - 角色档案（JSON格式）
  - `{角色ID}.json` - 角色档案
- `materials/extracted/` - 提取的信息
  - `plots/` - 情节提取
  - `scenes/` - 场景提取
  - `summaries/` - 摘要提取
  - `worldbuilding.md` - 世界观提取（新增）
  - `{自定义类型}/` - 用户自定义提取类型
- `backup/` - 版本快照
- 根目录文件（新增）：
  - `style-guide.md` - 文风指南
  - `story-state.md` - 故事全局状态
  - `recent-context.md` - 近期上下文摘要

### M0203 文件项
**功能**：显示文件，点击打开到编辑区

**执行逻辑**：
1. 点击文件项
2. 调用 `/api/file?path={filepath}` 获取文件内容
3. 创建标签页（如果不存在）
4. 切换到该标签页
5. 在编辑区显示文件内容

### M0204 项目文件结构
**功能**：定义项目目录和文件的层级结构

**目录结构**：
```
projects/{项目名}/
├── meta.json              # 项目配置
├── context.json            # 上下文统计
├── outline.md             # 大纲文件
├── style-guide.md         # 文风指南（新增）
├── story-state.md          # 故事全局状态（新增）
├── recent-context.md       # 近期上下文摘要（新增）
├── backup/                 # 版本快照目录
├── chapters/               # 章节目录
│   ├── vol-{序号}/        # 卷目录
│   │   ├── vol-meta.json   # 卷元数据
│   │   └── ch-{序号}/     # 章目录
│   │       ├── ch-meta.json  # 章元数据（含memory）
│   │       ├── sec-{序号}.md  # 节内容文件
│   │       ├── feedback/      # 用户反馈目录（新增）
│   │       │   └── {feedback_id}.json
│   │       └── revision-log/   # 修改日志目录（新增）
│   │           └── {revision_id}.json
│   └── vol-02/
├── characters/              # 角色档案目录
│   └── {角色ID}.json     # 角色档案
└── materials/             # 素材库目录
    └── extracted/         # 提取结果目录
        ├── worldbuilding.md # 世界观提取（新增）
        ├── plots/         # 情节提取
        │   └── {情节ID}.json
        ├── scenes/        # 场景提取
        │   └── {场景ID}.json
        ├── summaries/     # 摘要提取
        │   └── {章节ID}_{序号}.md
        └── **用户自定义**/    # 用户自定义提取类型
            └── {自定义ID}.json
```

**序号规则**：
- 卷：`vol-01`, `vol-02`, ...（每卷重置）
- 章：`ch-001`, `ch-002`, ...（全局连续）
- 节：`sec-001`, `sec-002`, ...（全局连续，每章固定4节）

### M0205 空状态
**功能**：未打开项目时显示提示

**执行逻辑**：
1. 未打开项目时，显示"选择或创建项目"
2. 打开项目后，显示文件树

## M03 中间编辑器区

### M0301 标签页栏
**功能**：多文件标签管理

**执行逻辑**：
1. 打开新文件时，创建标签页
2. 标签页过多时自动折叠
3. 点击标签，切换到对应文件，同时显示该文件的Prompt
4. 点击关闭按钮，关闭标签页
5. 关闭时提示保存未保存内容

### M0302 工具栏

#### M0302-1 润色按钮
**功能**：执行润色管线（去AI味 → 提升文笔 → 修正逻辑 → 优化节奏）

**执行逻辑**：
1. 获取当前文件内容
2. 将任务加入执行队列
3. L1模式：生成完成后等待确认
4. L2模式：自动继续下一个排队任务

#### M0302-2 生成下一部分按钮
**功能**：创建下一个编号文件并执行生成管线

**执行逻辑**：
1. 获取当前文件名，尝试解析末尾数字（chapter-1 → chapter-2）
2. 若无数字，追加 `-2` 后缀（file.md → file-2.md）
3. 创建新文件并打开到编辑器
4. 切换到「快捷」Tab
5. 将 generate 管线任务加入执行队列
6. 生成完成后从磁盘刷新编辑器内容

#### M0302-3 生成按钮
**功能**：执行生成管线（整合上下文 → 大纲对齐 → 写作初稿 → 去AI味 → 逻辑修正 → 优化节奏）

**执行逻辑**：
1. 将任务加入执行队列
2. 管线按步骤依次执行
3. 最终输出根据模式追加或覆盖当前文件

#### M0302-4 重写按钮
**功能**：执行重写管线（诊断问题 → 重写初稿 → 去AI味 → 逻辑修正 → 优化节奏）

**执行逻辑**：
1. 将任务加入执行队列
2. 管线按步骤依次执行
3. 最终输出覆盖当前文件

#### M0302-5 提取按钮
**功能**：执行提取管线（世界观 → 角色 → 情节 → 摘要）

**执行逻辑**：
1. 将任务加入执行队列
2. 管线按步骤依次执行
3. 提取结果写入对应文件

#### M0302-6 自定义按钮
**功能**：执行用户创建的自定义管线

**执行逻辑**：
1. 点击展开自定义管线下拉菜单
2. 选择管线后加入执行队列

#### M0302-7 后退按钮
**功能**：恢复到上一个版本快照

**执行逻辑**：
1. 从版本快照列表中获取"当前版本的上一个版本"
2. 恢复文件到该版本
3. 更新编辑区内容
4. 更新快照指针

#### M0302-8 前进按钮
**功能**：恢复下一个版本快照

**执行逻辑**：
1. 从版本快照列表中获取"当前版本的下一个版本"
2. 恢复文件到该版本
3. 更新编辑区内容
4. 更新快照指针

#### M0302-9 停止按钮
**功能**：停止当前正在执行的任务

**执行逻辑**：
1. 停止当前 streaming（聊天/生成）
2. 取消队列中正在运行的任务
3. 排队中的任务保留不动

### M0303 编辑区

#### M0303-1 空状态占位符

## M04 右侧面板

### M0401 Tab标签
**功能**：切换右侧面板各功能模块

**展示**：6个Tab — 快捷（⚡）、管线编辑（🔧）、工作流（📋）、故事状态（📖）、文风（🪶）、执行（📋）

**说明**：
- 「快捷」Tab：管线下拉选择 + 步骤选择 + Prompt 编辑 + 运行按钮
- 「管线编辑」Tab：步骤管理、Prompt 编辑、新建/保存管线
- 「故事状态」「文风」Tab：查看和编辑系统文件
- 「执行」Tab：任务队列 + 执行日志

### M0402 Prompt面板

#### M0402-1 标题
**功能**：显示Prompt编辑区标题

**展示**：
- 管线模式："当前步骤 Prompt（可直接编辑）"
- 自由模式："提示词（自由编辑）"

#### M0402-2 内容区
**功能**：显示和编辑Prompt内容

**执行逻辑**：
1. 根据当前操作类型，加载对应Prompt模板
2. 替换变量（@{文件路径} 等）
3. 显示Prompt内容
4. 用户编辑时，实时保存到后端

#### M0402-3 引用文件
**功能**：Prompt中引用的文件以链接展示

**执行逻辑**：
1. 解析Prompt内容中的 @{文件路径} 引用
2. 渲染为超级链接样式
3. 点击链接，打开对应文件到编辑区

#### M0402-G0125 文件树拖拽到 Prompt
**功能**：从文件树拖拽文件到 Prompt 编辑框

**执行逻辑**：
1. 文件树的文件节点设置 `draggable="true"`
2. 拖拽时，将文件路径存入 `DragEvent.dataTransfer`
3. Prompt 编辑框监听 `drop` 和 `dragover` 事件
4. 文件拖入时，在光标位置插入 `@{文件路径}` 引用
5. 下方的"引用文件"区域自动解析并显示为可点击链接
6. 点击链接可打开对应文件到编辑区

**涉及文件**：
- `frontend/src/components/file-tree/TreeNode.vue` — 拖拽源
- `frontend/src/components/right-panel/PromptPanel.vue` — 放置目标

#### M0402-G0126 自定义 Prompt 传入 Pipeline
**功能**：右侧面板中手工修改的 Prompt 传递到生成 pipeline

**执行逻辑**：
1. 用户在 Prompt 编辑框中修改内容
2. 内容通过 `rightPanelStore.promptContent` 持久化
3. 点击"写下一部分"时，`handleGenerateNext` 从 store 读取自定义 prompt
4. 若 prompt 长度 > 50 字符，作为 `extra_vars.user_prompt` 传入 pipeline API
5. 后端 pipeline 将 `user_prompt` 注入模板变量
6. 若 prompt 模板中引用了 `{{ user_prompt }}`，自定义内容即可生效

**涉及文件**：
- `frontend/src/components/editor/EditorToolbar.vue` — 读取并传入
- `frontend/src/composables/useFileGeneration.ts` — API 请求体加入 extra_vars

#### M0402-4 前进/后退
**功能**：查看/恢复Prompt历史版本

（同 M0302-3、M0302-4）

### M0404 工作流面板 ✨NEW

**功能**：查看、运行和编辑工作流（多步骤编排流水线）
**位置**：右侧面板 → 「📋 工作流」Tab

#### M0404-1 列表视图
**展示**：所有可用工作流卡片
- 工作流名称 + 步骤数
- 描述
- 默认变量值展示
- 编辑（🖊）和删除（🗑）操作按钮

#### M0404-2 详情视图
**功能**：查看工作流详情和运行
- 步骤预览树（含类型图标 ⚡管线/🔄循环/📁文件）
- 变量配置输入（可覆盖默认值）
- 运行按钮 → SSE 流式输出执行进度
- 实时执行日志（步骤开始/完成、循环迭代进度、错误信息）

#### M0404-3 编辑器视图
**功能**：新建或编辑工作流

**编辑内容**：
1. 基本信息：标识名、名称、描述
2. 变量管理：动态添加/删除键值对
3. 步骤管理：
   - 添加步骤 → 可上下移动排序
   - 三种类型切换（pipeline/loop/file），切换时自动清空无关字段
   - Pipeline 配置：管线名、输出路径、覆盖/追加模式
   - Loop 配置：循环次数、变量名、子步骤（递归编辑）
   - File 配置：操作类型（mkdir/copy/delete）、路径
4. 保存按钮 → 序列化为 YAML → POST 到后端

## G 全局功能

### G0101 版本快照系统

**功能**：记录文件修改历史，支持回退

**执行逻辑**：
1. 用户开始编辑：启动/重置10秒定时器
2. 定时器触发：生成版本快照，保存到 `backup/{filename}/`
3. 保留最近20个版本
4. 前进/后退：恢复对应版本

### G0102 LLM工作堆栈

**功能**：统一管理所有LLM任务

**执行逻辑**：
1. 任务入栈：用户发起 + 系统产生
2. 按顺序依次执行
3. L1模式：每步需确认
4. L2模式：自动连续执行

### G0103 SSE事件处理

**功能**：实时接收服务器推送

**事件类型**：
| 事件 | 触发时机 | 处理逻辑 |
|------|---------|---------|
| `generation` | AI生成内容 | 编辑器内逐字/逐段显示 |
| `file-created` | 新文件创建 | 刷新文件树 |
| `file-updated` | 文件更新 | 更新编辑器内容（含frontmatter） |
| `file-renamed` | 文件被重命名 | 刷新文件树，更新打开的标签页路径 |
| `directory-created` | 目录被创建 | 刷新文件树 |
| `task` | 任务状态变化 | 更新任务卡片 |
| `queue` | 队列变化 | 刷新堆栈列表 |
| `llm-status` | LLM状态变化 | 更新状态灯 |
| `thinking` | AI思考中 | 显示"AI正在思考..." |
| `error` | 错误 | 显示错误横幅 |
| `done` | 任务完成 | 停止加载动画，显示完成提示 |

**说明**：
- 文件不支持物理删除，不提供 `file-deleted` 事件

3. 用户编辑Prompt后保存到后端
4. 版本快照记录Prompt历史

### G0107 新建项目流程

**功能**：引导用户完成项目创建

**执行逻辑**：
1. 步骤1：生成书名+创意（AI生成，用户确认/编辑）
2. 步骤2：生成章节大纲（AI根据规模和参数生成大纲，确定卷/章/节结构）
3. 步骤3：用户确认大纲后，系统自动生成目录结构（包含新增文件）
4. 打开项目，进入写作模式

**详细流程**：
- 用户选择创作参数（题材、基调、背景、主题、写作风格）
- 用户选择作品规模（5万/10万/15万/20万字）
- 点击"创建项目"后进入三阶段引导

### G0108 项目完成度计算

**功能**：计算项目的完成百分比

**执行逻辑**：
```
完成度 = (有内容的节文件数) / (大纲中计划的节总数) × 100%
```
- 节文件有实际内容（字数 > 0）才算完成
- 空文件不计入完成数
- 废弃节（status: discarded）不计入

**统计范围**：
- 扫描 `chapters/` 下所有 `vol-*/ch-*/sec-*.md` 文件
- 读取每个 `sec-*.md` 文件的字节数或字数
- 读取对应章节的 `ch-meta.json` 获取状态
- 汇总到 `context.json` 的 stats 字段

**stats 字段示例**：
```json
{
  "stats": {
    "total_words": 25000,
    "total_sections": 14,
    "completed_sections": 5,
    "chapter_count": 3,
    "volume_count": 1,
    "character_count": 8
  }
}
```

### G0109 自定义参数管理

**功能**：管理用户自定义的创作参数

**执行逻辑**：
1. 预设参数：题材、基调、背景、主题、写作风格
2. 用户可新增/编辑/删除自定义选项
3. 保存到 `customParams` 配置项

### G0110 目录生成系统

**功能**：根据作品规模自动生成卷/章/节三级目录和文件

**执行逻辑**：
1. 根据选择的规模（5万/10万/15万/20万字）
2. 计算节数：总字数 / 1800（每节约1800字）
3. 计算章数：节数 / 4（每章固定4节）
4. 计算卷数：章数 / (8~15)（每卷8-15章）
5. 生成目录结构（包含新增文件：style-guide.md、story-state.md、recent-context.md）
6. 初始化 `vol-meta.json`（卷名称）
7. 初始化 `ch-meta.json`（章名称、memory、story_state、pending_foreshadowing、active_quests）
8. 创建空的 `sec-{序号}.md` 文件

**序号规则**：
- 卷序号：vol-01, vol-02, ...（每卷重置）
- 章序号：ch-001, ch-002, ...（全局连续，不随卷重置）
- 节序号：sec-001, sec-002, ...（全局连续，每章固定4节）

### G0116 自动化执行模式

**功能**：控制AI任务的执行方式

**自动化等级说明**：
| 等级 | 名称 | 说明 |
|------|------|------|
| L1 | 半自动 | 每步操作需要用户确认后，AI才执行下一步 |
| L2 | 连续 | 自动连续执行，AI完成当前步骤后自动开始下一步 |

**执行逻辑**：
1. L1 模式：生成完成后暂停，等待用户点击"继续"
2. L2 模式：自动生成下一章，不等待确认
3. 用户可随时切换模式
4. 切换后立即生效

### G0117 SSE重连机制

**功能**：保证SSE连接稳定性

**执行逻辑**：
1. 监听 SSE 连接断开事件
2. 断开后自动尝试重连
3. 重连间隔：1秒 → 2秒 → 4秒 → 8秒（指数退避）
4. 最大重试次数：10次
5. 重连成功后恢复所有状态
6. 重连失败后显示错误提示

**触发时机**：
