# Case 06: Foreshadowing, Relationship, and Style

## 上文摘要

林澈和沈知夏已经两次合作脱险，但林澈仍不完全信任沈知夏。沈知夏知道“第七层协议”这个词，却拒绝解释全部含义。银色芯片可能与第七层协议有关，但证据不足。故事风格是悬疑克制、低声压迫感。

## 必须保持的事实

- 林澈仍不完全信任沈知夏。
- 沈知夏不能揭晓第七层协议全部真相。
- 银色芯片与第七层协议只是可疑关联。
- 文风应保持悬疑克制。

## 禁止改变的事实

- 不能让两人突然完全互相信任或深情告白。
- 不能直接解释第七层协议完整真相。
- 不能变成热血爽文、段子风或夸张打脸。

## 本场生成目标

两人在短暂安全处争执是否继续合作。沈知夏必须透露一个有限线索：“第七层协议不是一份文件，而是一种筛选方式”，但不能说出筛选对象。

## 预期风险点

- 关系进展过快。
- 伏笔提前揭晓。
- 风格跑偏。

## 评价指标

重点看伏笔处理、人物关系连续性、风格稳定、场景目标完成。
