## ⚠️ 强制规则（AI代码生成必读）

**本文档是代码生成的强制性规范，不可忽略。**

每次生成代码前，AI必须：
1. **完整读取本文档**
2. **严格使用本文档列出的所有库**，不得自己重写功能
3. **禁止使用**本文档明确指出的"禁止引入"的库

**违反后果**：如果AI生成的代码没有使用本文档指定的库（比如自己写了HTTP请求而不是用httpx，自己写了模板引擎而不是用Jinja2），视为**代码不合格**，必须重写。

### 1.1 核心框架

| 库名 | 版本 | 用途 | 强制理由 |
|------|------|------|----------|
| **FastAPI** | ^0.110.0 | Web框架 | 异步原生支持、自动生成API文档、Pydantic集成 |

**强制要求**：
- ✅ 必须使用FastAPI构建所有API端点
- ✅ 必须使用`async def`定义异步端点
- ✅ 必须使用`StreamingResponse`处理SSE事件流
- ❌ 禁止手动构造SSE响应（必须用它FastAPI的原生支持）

**代码示例**：
```python
from fastapi import FastAPI
from fastapi.responses import StreamingResponse

app = FastAPI()

@app.get("/api/generate")
async def generate_text(prompt: str):
    async def generate():
        async for chunk in llm_stream(prompt):
            yield f"data: {chunk}\n\n"
    return StreamingResponse(generate(), media_type="text/event-stream")
```

### 1.2 LLM集成

| 库名 | 版本 | 用途 | 强制理由 |
|------|------|------|----------|
| **LiteLLM** | ^1.35.0 | 统一多模型调用 | 一套代码支持100+模型，避免写if-else |

**强制要求**：
- ✅ 必须使用LiteLLM调用所有LLM（OpenAI、Ollama、Claude等）
- ✅ 必须使用LiteLLM的流式输出接口
- ❌ 禁止为每个模型写单独的调用代码
- ❌ 禁止使用`openai`库直接调用（必须通过LiteLLM）

**代码示例**：
```python
from litellm import completion

async def call_llm(model: str, messages: list):
    response = completion(
        model=model,  # 可以是 "gpt-4", "ollama/llama2", "claude-2" 等
        messages=messages,
        stream=True
    )
    async for chunk in response:
        yield chunk.choices[0].delta.content or ""
```

### 1.4 Token计数

| 库名 | 版本 | 用途 | 强制理由 |
|------|------|------|----------|
| **tiktoken** | ^0.5.0 | 计算字符串的token数 | OpenAI官方库，准确计算上下文长度 |

**强制要求**：
- ✅ 调用LLM前必须使用tiktoken计算token数
- ✅ 必须检查是否超过模型上下文限制
- ❌ 禁止手动估算token数

**代码示例**：
```python
import tiktoken

    enc = tiktoken.encoding_for_model(model)
    return len(enc.encode(text))

# 使用前检查

    raise ValueError("Prompt too long")
```

**代码示例**：
```python
import frontmatter
import aiofiles

# 读取
async def read_file_with_frontmatter(path: str):
    async with aiofiles.open(path, mode="r", encoding="utf-8") as f:
        content = await f.read()
    post = frontmatter.loads(content)
    return post

# 写入
async def write_file_with_frontmatter(path: str, content: str, metadata: dict):
    post = frontmatter.Post(content, **metadata)
    md_text = frontmatter.dumps(post)
    async with aiofiles.open(path, mode="w", encoding="utf-8") as f:
        await f.write(md_text)
```

**代码示例**：
```python

def compare_versions(old_text: str, new_text: str) -> str:
    diff = difflib.unified_diff(

        new_text.splitlines(),
        fromfile='版本1',
        tofile='版本2'
    )
    return '\n'.join(diff)
```
