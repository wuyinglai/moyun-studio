# 墨韵 - AI 小说创作助手 产品说明

## 一、产品概述

> 更新说明（2026-05-20）：墨韵当前产品方向已从“单一自动化写作工具”调整为“爽文模式 + 专业模式”的人机协同创作平台。旧文中“大纲生成、全流程自动化”仍作为专业能力和历史兼容保留，但不再是唯一主流程。新版架构见 [产品架构-人机协同工作流.md](产品架构-人机协同工作流.md)。

### 1.1 产品名称
墨韵 - AI 小说创作助手

### 1.2 产品定位
一款面向中文小说创作者的 AI 辅助写作工具，通过 AI 技术帮助用户持续创作长篇小说。产品同时支持轻量的爽文模式和可配置的专业工作台。

### 1.3 核心价值
- **零门槛创作**：爽文模式通过开局卡、爽点卡、流式生成和候选稿降低使用门槛
- **长篇连续性**：通过故事引擎、近期上下文、质量摘要和记忆更新保证前后衔接
- **灵活控制**：专业模式提供 Prompt、管线、工作流、变量、文件节点和人工节点
- **实时协作**：通过 SSE 实时显示 AI 生成过程，让用户知道系统正在做什么
- **安全修改**：重写、润色、聊天改稿等高风险操作优先生成候选稿，采用后才覆盖正式文件

### 1.4 目标用户
- 普通网文用户：想快速写爽文，从写小说中获得快乐
- 进阶作者：需要控制人物、节奏、伏笔和长篇连续性
- Prompt/工作流用户：希望自定义 AI 写作流程、节点和文件操作

## 二、界面布局

### 2.1 整体结构
采用经典的三栏布局：
- **左侧边栏**（约240px）：文件树，显示项目文件结构
- **中间主区域**（flex:1）：编辑器+聊天区，核心工作区
- **右侧面板**（约320px，可拖拽调整）：Prompt/自动化/执行面板

### 2.2 顶部工具栏
高度约60px，从左到右依次为：
1. **Logo区域**：墨韵图标 + 文字（feather-pointed 图标）
2. **项目名称**：显示当前打开的项目名（可点击编辑，内联输入框）
3. **通知区域**：顶部中间，用于操作成功/失败 Toast 提示
4. **LLM连接状态**：状态点 + 文字（"已连接"/"未连接"），可点击打开设置；额外 SSE 状态指示点
5. **LLM调用中**：调用时显示旋转动画 + 当前操作名称（"正在续写章节..." / "正在重写章节..." / "AI生成中..."）
6. **Thinking开关**：开关控件，控制 AI 思考模式
7. **操作按钮**：
   - 打开项目（次要按钮，文件夹图标）
   - 新建项目（主要按钮，渐变背景色，加号图标）
   - 设置（图标按钮，齿轮图标）

### 2.3 左侧文件树
- 标题栏：显示"文件"+ 刷新按钮
- 树形结构：支持展开/折叠
- 文件类型图标：区分文件夹和文件
- 空状态：未打开项目时显示"选择或创建项目"
- 文件夹用途：
  - `chapters/` - 章节文件（卷/章/节三级结构）
    - `vol-{序号}/` - 卷目录
      - `vol-meta.json` - 卷元数据
      - `ch-{序号}/` - 章目录
        - `ch-meta.json` - 章元数据（含memory）
        - `sec-{序号}.md` - 节内容文件
  - `characters/` - 角色档案（JSON格式）
    - `{角色ID}.json` - 角色档案
  - `materials/extracted/` - 提取的信息
    - `plots/` - 情节提取
    - `scenes/` - 场景提取
    - `summaries/` - 摘要提取
    - `{自定义类型}/` - 用户自定义提取类型
  - `backup/` - 版本快照

### 2.4 中间编辑器区
- **标签页栏**：多文件标签，支持切换和关闭
- **工具栏**（按钮均为 outline 风格）：
  - 后退 / 前进：编辑器撤销/重做
  - 润色 / 生成 / 重写 / 提取：快捷运行管线
  - 自定义：下拉菜单显示自定义管线列表
  - 写下一部分：自动创建下一个序号文件并运行生成管线
  - 更多：下拉菜单包含 Token 计数、对比、反馈、修改日志、批量生成、质量审查
  - 停止（红色，任务进行中时显示）
- **编辑区**：
  - 占位符：未打开文件时显示"打开左侧文件开始编辑..."
  - 内容区：代码编辑器（Ant Design Vue 的 Textarea），支持 Markdown 编辑
  - 状态提示：右上角显示保存状态
- **聊天区**（位于编辑器下方）：
  - 消息列表：显示对话历史
  - 输入框：多行文本输入
  - 发送按钮：纸飞机图标

### 2.5 右侧面板
共 5 个 Tab 标签页切换：

1. **快捷面板**（默认，⚡ 标签）：
   - 管线选择器（下拉选择，含"自由编辑"模式）
   - 运行按钮（自由编辑模式显示"发送"，管线模式显示"运行"）
   - 步骤标签（管线模式显示各步骤，可点击切换）
   - Prompt 编辑区（支持 @{path} 引用文件，显示引用文件列表）
   - 状态指示：生成中 / 空闲

2. **管线编辑面板**（🔧 标签）：
   - 管线列表
   - 步骤管理（增删改步骤）
   - Prompt 内容编辑器

3. **故事状态面板**（📖 标签）：
   - 显示当前项目 story-state.md 内容
   - 可编辑和保存

4. **文风面板**（🪶 标签）：
   - 显示 style-guide.md 内容
   - 可编辑和保存

5. **执行面板**（📋 标签）：
   - 执行日志列表
   - 任务进度展示

### 2.6 模态框
- **新建项目模态框**：
  - 创作参数选择：题材/基调/背景/主题/写作风格（按钮组，单选）
  - 作品规模：5万/10万/15万/20万字

  - 点击"创建项目"后进入三阶段引导流程

- **打开项目模态框**：
  - 项目列表：显示项目名、创建时间、完成度
  - 操作：打开、删除

- **设置模态框**：
  - 三个 Tab 切换：AI 设置 / 自动化 / 外观

  - 自动化：自动化等级单选（L1 半自动 / L2 连续（规划中）），L2 当前为 UI 占位，功能尚未完整实现
  - 外观：主题选择（深邃夜紫/墨绿护眼/经典炭灰），带渐变预览色块

## 三、核心功能流程

### 3.1 新建项目流程
```
1. 点击"新建"按钮
2. 弹出创建项目模态框
3. 选择创作参数（题材/基调/背景/主题/风格）
4. 选择作品规模（5万/10万/15万/20万字）
5. 点击"创建项目"
6. 进入三阶段引导流程：
   - 阶段1：AI生成书名+创意 → 用户确认/编辑
   - 阶段2：AI生成大纲（含卷/章/节结构） → 用户确认/编辑
   - 阶段3：自动生成目录结构，开始写作
7. 完成创建，打开项目
```

**目录生成规则**：
- 根据作品规模计算总节数：总字数 / 1800（每节约1800字）
- 章序号全局连续，每章节数由规模动态计算
- 自动划分卷（通常8-15章一卷）
- 生成的三级目录结构：
  ```
  chapters/
  ├── vol-01/
  │   ├── vol-meta.json
  │   ├── ch-001/
  │   │   ├── ch-meta.json
  │   │   ├── sec-001.md
  │   │   ├── sec-002.md
  │   │   ├── sec-003.md
  │   │   └── sec-004.md
  │   └── ch-002/
  └── vol-02/
  ```
- 同时生成 `characters/`、`materials/extracted/`、`backup/` 目录

### 3.2 编辑器操作流程
```
1. 从文件树点击打开文件
2. 在编辑器中查看/编辑内容
3. 点击工具栏按钮触发AI操作：
   - 润色：AI润色当前文件内容
   - 生成：管线续写生成
   - 重写：AI重新生成整个文件内容
   - 提取：从当前文件提取素材
   - 写下一部分：创建下一个顺序文件并运行生成管线
4. 右侧面板实时显示Prompt
5. 执行面板显示任务进度
6. 完成后自动更新文件内容

"写下一部分" 自动计算逻辑：从当前文件名中提取数字序号并递增（如 `sec-003.md` → `sec-004.md`），若文件名不含数字则在末尾追加 `-2`。新文件创建后自动以 generate 管线生成内容。

### 3.3 AI对话流程
```
1. 在底部聊天输入框输入需求
2. 点击发送或按Enter
3. 消息显示在聊天区（用户消息靠右）
4. AI开始处理，显示"LLM调用中"
5. AI回复流式显示在聊天区（AI消息靠左）
6. 完成后隐藏"LLM调用中"状态
```

### 3.4 自动化等级
- **L1 半自动**（当前，默认）：每步操作需要用户确认后，AI 才执行下一步
- **L2 连续**（规划中）：连续执行模式，无需每步确认。UI 已预留选项但功能尚未实现

## 八、技术要点

### 8.1 前端技术栈
- Vue 3 + TypeScript（组合式 API、\<script setup\> 语法）
- Vite 构建工具
- Pinia 状态管理（persist 插件 + localStorage 持久化）
- Vue Router 路由管理
- Ant Design Vue 组件库
- SSE（EventSource）实时通信
- Font Awesome 6.4 + emoji 图标

### 8.2 后端技术栈
- Python 3.10+ + FastAPI
- LiteLLM 统一 LLM 调用层（支持 OpenAI / Claude / DeepSeek / Azure / Ollama）
- SSE 事件推送（EventBus 模式，事件类型用 `:` 分隔，SSE 桥自动替换为 `-`）
- aiofiles 异步文件读写
- Pydantic v2 数据验证
- Jinja2 模板渲染（Prompt 模板）

### 8.3 后端架构分层
- **五层架构**：`api/` → `application/` → `domain/` → `infrastructure/` + `schemas/`
- **api/ 层**：HTTP 路由、参数校验、响应格式化
- **application/ 层**：用例编排、事务控制
- **domain/ 层**：核心业务逻辑、实体、值对象
- **infrastructure/ 层**：文件 I/O、第三方服务集成
- **schemas/**：Pydantic 请求/响应模型，供所有层共同引用

### 8.5 数据流
```
用户操作 → 前端 API 请求 → 后端 api/ 路由 → application/ 层编排 →
domain/ 层处理业务逻辑 → infrastructure/ 层执行文件 I/O →
Pipeline 编排多步骤 LLM 调用 → 每步通过 SSE 推送事件 →
前端 EventSource 接收事件 → Pinia store 更新状态 → UI 自动刷新
```

### 13.1 文件结构
```
workspace/                            # 工作区根目录
├── projects/                        # 所有项目目录
│   └── {project_name}/             # 项目名称（唯一标识）

│       ├── chapters/               # 章节目录
│       │   └── vol-{序号}/        # 卷目录
│       │       ├── vol-meta.json   # 卷元数据
│       │       └── ch-{序号}/     # 章目录
│       │           ├── ch-meta.json  # 章元数据（含memory）
│       │           └── sec-{序号}.md  # 节内容文件
│       ├── characters/              # 角色档案目录
│       │   └── {角色ID}.json     # 角色档案
│       ├── materials/             # 素材库目录
│       │   └── extracted/         # 提取结果目录
│       │       ├── plots/         # 情节提取
│       │       ├── scenes/        # 场景提取
│       │       └── summaries/     # 摘要提取

### 12.4 质量保障功能

#### 文风指南 (style-guide.md)
- 定义小说的文风要求，指导 AI 生成符合期望的文字风格
- 包含语言风格、句子节奏、描写密度、语言特点等要素
- 支持用户自定义文风示例

#### 故事全局状态 (story-state.md)
- 记录小说的全局状态，包括主角当前状态、势力变化、伏笔追踪等
- 每次生成新章节后自动更新
- 包含主线/支线进度追踪

#### 近期上下文 (recent-context.md)
- 存储最近5章的摘要
- 用于在生成章节时提供近期情节上下文
- 每次生成章节后自动追加

#### 用户反馈 (feedback/)
- 用户提交反馈时创建反馈记录
- 保存到章节目录下 `feedback/` 子目录
- 支持查看和管理反馈记录

#### 修改日志 (revision-log/)
- AI重写或用户修改时创建修改日志
- 保存到章节目录下 `revision-log/` 子目录
- 支持查看修改历史和版本对比
