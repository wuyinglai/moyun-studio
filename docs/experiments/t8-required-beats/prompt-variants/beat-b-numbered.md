# Variant B: Numbered Required Beats

Required beats are listed as numbered mandatory items:

```text
【本场必须完成的 4 个信息点】
1. 林澈必须发现“第七层协议”这个词。
2. 银色芯片必须显示一个残缺坐标。
3. 追踪者必须进入旧港站地下层。
4. 正文必须自然包含以上 4 点，不能漏掉任何一点。
```

Hypothesis:

Numbering makes omissions easier for the model to notice and may improve required-beat completion.
