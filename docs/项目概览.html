项目目录结构

├── meta.json                # 项目配置
├── context.json             # 上下文统计

│   └── vol-{序号}/
│       ├── vol-meta.json
│       └── ch-{序号}/
│           ├── ch-meta.json
│           ├── sec-{序号}.md

📋 核心原则
✅ 文档优先 - 所有代码实现前，先确认文档完备
✅ 契约驱动 - 功能清单、API 契约 = 开发契约
✅ Prompt 独立 - Prompt 必须独立存储，禁止硬编码
✅ 验收钩子 - 每个模块开发完成后逐项打勾
✅ 文档同步 - 每次更新文档，检查所有依赖
✅ 追问到底 - "还有吗？"是口头禅
