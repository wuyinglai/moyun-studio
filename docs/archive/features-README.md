当前权威功能规格仍是 [../功能清单.md](../功能清单.md)。本目录用于后续把过大的功能清单拆成更小的主题文档。

## 计划拆分

| 未来文件 | 内容边界 |
| --- | --- |
| `lite-mode.md` | 爽文模式：开局卡、爽点卡、流式生成、候选稿、故事引擎摘要 |
| `professional-mode.md` | 专业模式：文件树、编辑器、Prompt、管线、工作流、变量池 |
| `workflow-nodes.md` | Workflow / Chain / Node、Human Node、File Node、Memory Node、Quality Node |
| `project-files.md` | 项目文件结构、卷章节目录、候选稿、快照、回收站 |
| `quality-and-memory.md` | 质量审稿、故事引擎、近期上下文、角色状态、伏笔更新 |

## 使用规则

- 拆分前，不要复制粘贴造成多份权威定义。
- 拆分后，`../功能清单.md` 应降级为总览和目录。
- 每个功能文档都要说明对应 API、前端页面、测试入口。
