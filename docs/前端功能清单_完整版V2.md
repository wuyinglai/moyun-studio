## 实时事件处理

### SSE 事件 (useSSE.ts → EventSource)

通过 `EventSource` 连接 `GET /api/events` 接收：

| 事件类型 | 处理流程 |
|----------|----------|
| `file-created` | `fileStore.refreshTree()` → 刷新文件树 |
| `file-updated` | `editorStore.updateContent(path, data.content)` → 更新编辑器内容（含frontmatter） |
| `file-renamed` | `fileStore.refreshTree()` → 刷新文件树，更新打开的标签页路径 |
| `directory-created` | `fileStore.refreshTree()` → 刷新文件树 |
| `task` | `taskStore.updateTask(taskId, data)` → 更新任务状态 |
| `queue` | `taskStore.refreshQueue()` → 刷新堆栈列表 |
| `llm-status` | `llmStore.updateStatus(data)` → 更新 LLM 状态灯 |
| `thinking` | `chatStore.currentThinking = data.content` → 显示思考过程 |
| `diff_summary` | `useDiffSummary().setSummary(data.summary, data.target_file)` → AI 修改摘要 |
| `error` | `notification.error(data.message)` → 显示错误横幅 |
| `done` | `chatStore.finishAIMessage()` + `llmStore.isGenerating = false` |

### AI 生成内容 (useFileGeneration.ts → fetch + ReadableStream)

管线执行时的生成内容**不经过 SSE EventSource**，而是通过 `fetch` + `ReadableStream` 接收：

| 通道 | 处理流程 |
|------|----------|
| `generation` | `generationEmitter` 分发 CustomEvent → `editorStore.appendContent(path, data.content)` 追加到编辑器 |
