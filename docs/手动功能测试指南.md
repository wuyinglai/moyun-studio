# 墨韵 - AI小说创作助手 手动功能测试指南

## 测试前准备

1. 确保前端运行在 http://localhost:5176/
2. 确保后端运行在 http://localhost:8000/ (如需要AI功能)
3. 打开浏览器访问应用

---

## M01 顶部工具栏测试

### M0101 Logo区域 ✅
**测试步骤**: 查看页面左上角是否显示"墨韵" Logo

### M0102 项目名称 ✅
**测试步骤**: 查看工具栏是否显示项目名称（未打开项目时可能为空）

### M0103 LLM连接状态 ✅
**测试步骤**: 
1. 查看工具栏右侧是否有状态指示灯（绿色/红色）
2. 状态文字是否显示"已连接"/"未连接"

### M0108 打开项目按钮 ✅
**测试步骤**:
1. 点击"打开项目"按钮
2. 检查是否弹出"打开项目"模态框
3. 检查是否显示项目列表
4. 点击关闭按钮或按ESC关闭

### M0109 新建项目按钮 ✅
**测试步骤**:
1. 点击"新建项目"按钮
2. 检查是否弹出"新建项目"模态框
3. 检查是否显示创作参数选项（题材、基调、背景等）
4. 检查是否显示作品规模选项（5万/10万/15万/20万字）
5. 关闭模态框

### M0110 设置按钮 ✅
**测试步骤**:
1. 点击"设置"按钮
2. 检查是否弹出"设置"模态框
3. 检查是否显示三个主题选项（深邃夜紫、墨绿护眼、经典炭灰）
4. 检查是否显示其他配置项
5. 关闭模态框

---

## M02 左侧文件树测试

### M0201 标题栏 ✅
**测试步骤**: 查看左侧是否显示"文件"标题

### M0202 文件夹展开/折叠 ✅
**测试步骤**:
1. 打开一个项目（如果已有项目）
2. 点击文件夹前面的箭头或文件夹本身
3. 检查文件夹是否展开/折叠
4. 检查子文件是否显示

### M0203 文件项 ✅
**测试步骤**:
1. 点击文件树中的文件
2. 检查编辑区是否加载文件内容
3. 检查是否创建新标签页

### M0205 空状态 ✅
**测试步骤**:
1. 未打开项目时，检查是否显示"选择或创建项目"
2. 打开项目后，检查是否显示文件树

---

## M03 中间编辑器区测试

### M0301 标签页栏 ✅
**测试步骤**:
1. 打开多个文件
2. 检查是否创建多个标签页
3. 点击不同标签，检查是否切换文件
4. 点击关闭按钮，检查是否关闭标签页

### M0302 工具栏按钮 ✅
**测试步骤**:
1. **后退按钮**: 点击后退按钮，检查是否撤销编辑
2. **前进按钮**: 点击前进按钮，检查是否重做
3. **重写按钮**: 点击重写按钮，检查是否触发AI重写
4. **生成下一个文件按钮**: 点击按钮，检查是否生成下一部分
5. **停止按钮**: AI生成时，检查是否显示停止按钮，点击是否停止生成

### M0303 编辑区 ✅
**测试步骤**:
1. 在编辑区输入文本
2. 检查是否实时显示
3. 检查保存状态（已保存/保存中...）
4. 空状态：未打开文件时，检查是否显示提示

### M0304 聊天区 ✅
**测试步骤**:
1. 在聊天输入框输入文字
2. 点击发送按钮或按Enter发送
3. 检查是否显示用户消息（右侧）
4. 检查AI响应（左侧）

---

## M04 右侧面板测试

### M0401 Tab标签 ✅
**测试步骤**: 查看右侧面板是否有Tab切换

### M0402 Prompt面板 ✅
**测试步骤**:
1. 检查标题是否为"当前 Prompt"
2. 检查前进/后退按钮是否显示
3. **前进后退功能**: 
   - 编辑Prompt后点击后退，检查是否恢复到之前的版本
   - 点击前进，检查是否前进到下一个版本
4. **Prompt编辑**:
   - 在Prompt编辑区输入文字
   - 等待500ms（自动保存）
   - 检查保存状态是否显示"已保存"
5. **空状态**: 初始时检查是否有占位提示

### M0403 执行面板 ✅
**测试步骤**:
1. 点击"执行"Tab切换到执行面板
2. 检查是否显示LLM工作堆栈
3. 检查是否显示任务卡片（等待中/执行中/已完成）
4. 检查是否显示执行日志区域

---

## M05 模态框测试

### M0501 新建项目模态框 ✅
**测试步骤**:
1. 点击"新建项目"按钮
2. 检查模态框标题
3. 检查创作参数选项是否完整
4. 检查作品规模选项
5. 点击"创建项目"或关闭

### M0502 打开项目模态框 ✅
**测试步骤**:
1. 点击"打开项目"按钮
2. 检查是否显示项目列表
3. 检查每个项目的名称和完成度
4. 点击项目后点击"打开"
5. 或点击删除按钮测试删除功能

### M0503 设置模态框 ✅
**测试步骤**:
1. 点击"设置"按钮
2. 检查三个主题选项
3. **主题切换测试**:
   - 点击"墨绿护眼"，检查界面颜色是否变化
   - 点击"经典炭灰"，检查界面颜色是否变化
   - 点击"深邃夜紫"，检查界面颜色是否变化
4. 检查API配置选项
5. 关闭模态框，检查主题是否保持

---

## M06 通知系统测试

### M0601 通知显示 ✅
**测试步骤**:
1. 执行某个操作（如打开设置再关闭）
2. 检查右上角是否显示通知
3. 检查通知样式（成功绿色/错误红色/警告黄色）
4. 检查是否自动消失（5秒后）
5. 检查是否有关闭按钮，点击是否关闭

---

## M07 拖拽调整测试

### M0701-M0703 分隔线 ✅
**测试步骤**:
1. 找到三个分隔线（左右侧边栏和编辑器/聊天区之间）
2. 鼠标悬停到分隔线，检查是否显示拖拽指示器
3. 拖动分隔线，检查宽度/高度是否实时调整
4. 松开鼠标，检查布局是否固定
5. 刷新页面，检查布局是否保持

---

## M08 主题系统测试

### M0801-M0803 三个主题 ✅
**测试步骤**:
1. 打开设置模态框
2. 点击"深邃夜紫"（默认主题），检查颜色
3. 点击"墨绿护眼"，检查整体变成绿色调
4. 点击"经典炭灰"，检查整体变成灰色调
5. 关闭设置，刷新页面，检查主题是否保持

---
