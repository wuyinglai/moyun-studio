# Variant D: Beat Outline First

The prompt asks the model to plan the required beats before drafting:

```text
先用 3-4 行在内部规划本场必须完成的信息点，然后严格按这些信息点写正文。
最终只输出正文。
```

Hypothesis:

A tiny beat outline may improve completion because it forces a local plan before prose. Risk: the model may expose the outline or produce mechanical prose.
