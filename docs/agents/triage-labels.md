# Triage Labels

技能使用5种标准分类状态。本文件将这些状态映射到实际使用的标签字符串。

| 状态 (mattpocock/skills) | 本项目标签 | 含义 |
|-------------------------|-----------|------|
| `needs-triage`          | `needs-triage`  | 维护者需要评估此问题 |
| `needs-info`            | `needs-info`    | 等待报告者提供更多信息 |
| `ready-for-agent`       | `ready-for-agent` | 完全规格化，AFK agent 可处理 |
| `ready-for-human`       | `ready-for-human` | 需要人工实现 |
| `wontfix`               | `wontfix`       | 不会处理 |

当技能提到某个状态（如"应用 AFK-ready 分类标签"）时，使用上表对应的标签字符串。

可直接编辑右侧列以匹配你实际使用的词汇。
