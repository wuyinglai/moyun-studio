## Writing Quality Loop

The writing quality loop is designed to reduce small-model omissions and logic drift without giving the model authority over official prose.

Flow:

1. User writes or opens a scene.
2. User optionally adds required / forbidden beats.
3. AI generates a candidate.
4. Validator records pass / warning / unknown metadata.
5. User previews the candidate.
6. User adopts, deletes, or creates a feedback revision candidate.

## Candidate Safety

Moyun Studio keeps official scene text protected:

- rewrite / polish / feedback revision create candidates;
- official text changes only after explicit adopt;
- warning confirmation is advisory but visible;
- delete/discard does not affect official text;
- adopt remains protected by file conflict checks.

## Feedback Revision

Pending candidates can produce child candidates from user feedback.

The child candidate records:

- parent candidate relationship;
- revision group;
- revision index;
- feedback text;
- inherited generation context where available.

Adopted, discarded, or rejected candidates are not revised directly.
