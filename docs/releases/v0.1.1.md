## Summary

v0.1.1 is a documentation-focused maintenance release. No new features or code changes. The focus is on improving the first-time user experience: clearer installation instructions, better configuration guidance, known issues documentation, and a formalized release checklist.

## Startup / Configuration Notes

- No code changes in this release. Backend and frontend behavior is identical to v0.1.0.
- The `.env.example` file now documents the `MOYUN_DISABLE_PROXY_DETECTION` environment variable, which resolves SSL connection errors on Windows when proxy settings interfere with aiohttp/httpx.
- If you are upgrading from v0.1.0, no `.env` changes are required unless you are experiencing Windows SSL issues.

## Known Issues

Unchanged from v0.1.0. See [docs/KNOWN_ISSUES.md](../KNOWN_ISSUES.md) for the full list:

1. No conflict detection on memory/material endpoints
2. Some non-core API files still use raw I/O
3. Real LLM E2E is optional (not in default release check)
4. Workspace `.config.json` stores API keys locally (intentional for local-first)
