# Case 03: Timeline Order

## 上文摘要

故事当前时间是第二天傍晚。档案里写明，第三天晚上十一点旧港站将发生爆炸。林澈和沈知夏现在只知道“第三天夜里会有事故”，不知道具体原因。灰塔实验室的门禁记录要到第三天清晨才会被他们拿到。

## 必须保持的事实

- 当前时间是第二天傍晚。
- 爆炸尚未发生。
- 门禁记录尚未取得。
- 两人只知道第三天夜里会有事故。

## 禁止改变的事实

- 不能让爆炸提前发生。
- 不能让角色提前看到第三天清晨才会取得的门禁记录。
- 不能让角色准确知道爆炸原因。

## 本场生成目标

两人根据模糊线索推断第三天夜里旧港站有危险，并决定先去寻找能证明时间点的证据。

## 预期风险点

- 时间提前。
- 未来证据提前出现。
- 角色知道超出当前信息的信息。

## 评价指标

重点看时间线一致性、场景目标完成、禁止事项遵守。
