## 2. Baseline

Baseline 表示当前生产 Prompt，不做额外约束。

实验用途：

- 作为对照组
- 记录当前字数、质量标记、人工评分
- 对比 Variant A-D 的效果

Baseline 不在本文档中复制生产 Prompt，避免文档和生产 Prompt 产生漂移。

实际 Baseline Prompt 位置：`prompts/generate/continuation/main.md`

## 3. Variant A：字数约束补丁

目标：解决 too_short 问题。

Prompt 补丁（追加到现有 Prompt）：

```text
### 字数约束

- 目标长度：1000-1500 中文字
- 最低不得少于 900 中文字
- 不要只写过渡段
- 不要用摘要代替正文
- 不要提前收束
- 正文应至少包含 6 个自然段
```

预期改善：

- 降低 too_short 概率
- 提高单场内容完整度

潜在风险：

- 可能为了凑字数增加废话
- 可能降低节奏密度

---

## 4. Variant B：字数 + 三段行动链

目标：在 Variant A 基础上，提高场景结构稳定性。

Prompt 补丁（追加到现有 Prompt）：

```text
### 字数约束

- 目标长度：1000-1500 中文字
- 最低不得少于 900 中文字
- 正文应至少包含 6 个自然段

### 行动链要求

本场至少包含 3 个行动段落：

1. **第一行动段**：角色主动采取行动
2. **第二行动段**：外部阻力出现或冲突升级
3. **第三行动段**：角色做出选择、付出代价或获得新信息

要求：

- 不要只写心理活动
- 不要只写环境描写
- 每个行动段落都必须推动情节变化
```

预期改善：

- 增强人物行动
- 减少空泛描写
- 提高连续生成可接续性

潜在风险：

- 场景结构可能变得机械
- 文本可能显得刻意

## 5. Variant C：字数 + 行动链 + 冲突推进 + 结尾钩子

目标：这是推荐优先测试的版本，平衡质量提升和约束复杂度。

Prompt 补丁（追加到现有 Prompt）：

```text
### 字数约束

- 目标长度：1000-1500 中文字
- 最低不得少于 900 中文字
- 至少 6 个自然段
- 不要用摘要代替正文

### 行动链要求

本场至少包含 3 个行动段落：

- 每个行动段落都要有明确的角色行动
- 行动必须带来新的信息、风险、冲突或选择

### 冲突推进要求

本场必须让以下至少一项发生变化：

- 主角处境更危险
- 目标更明确
- 敌对方行动升级
- 关键资源发生变化
- 人物关系发生变化
- 新信息出现

### 结尾钩子要求

- 结尾不要完全收束
- 结尾必须留下下一场可继续推进的问题、威胁、选择或行动
- 不要用"他不知道的是……"这类套路句
- 钩子应自然来自本场冲突

### 禁止事项

- 不要输出大纲
- 不要输出摘要
- 不要输出系统说明
- 不要出现"最近5章摘要"、"系统自动维护"、"占位"、"TODO"或模板占位符
```

预期改善：

- 降低 too_short
- 提升冲突推进
- 提高下一场可接续性
- 降低模板泄漏风险

潜在风险：

- Prompt 较长
- 可能增加模型执行成本
- 部分题材可能需要调整"冲突推进"定义

推荐结论：优先用 Variant C 做第一轮实验。

## 6. Variant D：完整约束 + 禁止模板词 + 降低 AI 腔

目标：最大限度降低低质量输出和 AI 腔。

Prompt 补丁（追加到现有 Prompt）：

```text
### 基础长度

- 目标长度：1000-1500 中文字
- 最低不得少于 900 中文字
- 至少 6 个自然段
- 禁止用摘要、说明、提纲替代正文

### 场景结构

本场至少包含 3 个行动段落：

- 每个行动段落必须包含：角色行动、外部反馈、局势变化
- 不要连续两段只写心理活动
- 不要连续两段只写背景解释

### 冲突推进

本场必须推进一个具体冲突：

- 敌人施压
- 资源减少
- 时间压力增加
- 关系恶化
- 新秘密暴露
- 主角被迫选择
- 计划出现偏差

### 人物表现

- 通过动作、对话、选择表现人物
- 少用抽象形容
- 少用总结性评价
- 不要替读者解释人物性格

### 结尾要求

- 结尾留下下一场可执行动作
- 结尾应包含未解决的压力或选择
- 不要完全解决本场全部矛盾

### 禁止输出

严禁出现以下内容：

- "以下是"
- "本章主要讲述"
- "总结来说"
- "最近5章摘要"
- "系统自动维护"
- "占位"
- "TODO"
- 模板占位符
- Markdown 表格
- JSON
- 大纲
- 说明文字
- 系统提示

### 风格要求

- 直接写正文
- 使用具体动作和感官细节
- 保持节奏紧凑
- 避免 AI 腔
- 避免空泛抒情
```

预期改善：

- 降低 template_leak
- 降低 AI 腔
- 增强文本可读性

潜在风险：

- 约束较重
- 可能导致模型过度遵循格式
- 可能牺牲自然感
- 可能不适合所有题材

## 7. 推荐实验顺序

建议实验顺序：

1. Baseline
2. Variant A
3. Variant C
4. Variant D
5. 如果 C 明显优于 A，再测试 B
6. 如果 D 过于生硬，则回退到 C

优先级：

| 优先级 | 变体 | 原因 |
|--------|------|------|
| 1 | Variant C | 平衡质量和自然度 |
| 2 | Variant A | 验证字数约束单独效果 |
| 3 | Variant D | 验证强约束极限 |
| 4 | Variant B | 作为结构约束中间态 |

第一轮推荐测试 Variant C。
