# Moyun Studio v0.1.2 Release Notes

## Release Type

Productization / Release-preflight Update — documentation and release readiness improvements.

## Release Date

2026-06-11

## Summary

v0.1.2 is a productization-focused release that prepares Moyun Studio for broader use. This release focuses on:
- Publishing a comprehensive release smoke checklist
- Organizing known issues into blockers vs non-blockers
- Enhancing UI safety copy for candidate/adopt workflows
- Completing T6.9 productization review phase

No breaking changes. No code API changes. Default behavior unchanged.

## Highlights

- ✅ **Release Smoke Checklist**: New comprehensive pre-release verification guide
- ✅ **Known Issues Classification**: Clear separation between release blockers and non-blocking issues
- ✅ **UI Safety Copy**: Enhanced candidate/adopt/preview messaging to prevent user confusion
- ✅ **E2E Coverage**: Verified candidate workflow and dry-run UI tests passing
- ✅ **Default Safety**: Real LLM calls disabled by default; no API keys used in tests

## What Changed

### Release Preflight Checklist

- **docs/release-preflight.md**: Added comprehensive Smoke Checklist section with 7 verification categories:
  - Git status verification (clean working tree, HEAD consistency)
  - Environment variable safety check (no real LLM smoke enabled)
  - Port availability check (5173 for frontend, 8000 for backend)
  - Backend startup verification
  - Frontend E2E critical test execution
  - Frontend build validation
  - Prohibited actions documentation

### Known Issues Organization

- **docs/known-issues.md**: Added two new sections:
  - **Release Blockers** (6 items): Issues that must be fixed before release
  - **Non-blocking Issues** (7 items): Known limitations that don't block release
- Clear severity categorization and target version assignments

### UI Safety Copy Improvements

- **CandidatePanel.vue**: Added notice "候选稿不会自动覆盖正文。你可以先预览，再决定是否采用。"
- **Preview Modal**: Added notice "预览只用于查看内容，不会修改正文。"
- **Adopt Confirmation**: Enhanced dialog with conflict check explanation
- **ProfessionalQuickPanel.vue**: Added safety hint "生成结果会先保存为候选稿，不会直接覆盖正文。"
- **ExecutionPanel.vue**: Added dev-tools subtitle "仅用于验证流程，不会调用真实 LLM，不会写入正文"

### E2E Verification Updates

- **tests/e2e/14-candidate-workflow.spec.ts**: Added assertions for safety copy visibility
- **tests/e2e/24-dry-run-ui-entry.spec.ts**: Added assertions for dev-tools subtitle
- Both test suites passing (6 passed + 4 passed)

### Roadmap Updates

- **docs/roadmap/t6-7-productization-roadmap.md**: Marked T6.9.0, T6.9.1, T6.9.2, T6.9.3 as complete
- Updated release status tracking for productization phase
