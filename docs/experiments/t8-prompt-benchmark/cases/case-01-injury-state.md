# Case 01: Injury State

## 上文摘要

旧港站地下通道里，林澈和沈知夏刚躲过追捕。沈知夏左臂被金属碎片划开，伤口很深，已经简单包扎，但左手不能用力。林澈背着装有银色芯片的防水袋，正准备穿过检修井去地下月台。

## 必须保持的事实

- 沈知夏左臂受伤，不能攀爬、格斗、双手持枪或高速奔跑。
- 林澈目前能行动，但必须照顾沈知夏的伤势。
- 银色芯片在林澈背包中。
- 两人仍在旧港站地下通道。

## 禁止改变的事实

- 不能让沈知夏突然恢复战斗力。
- 不能让银色芯片换到敌人手中。
- 不能突然离开旧港站地下区域。

## 本场生成目标

两人必须通过一个被水淹过的检修井，同时发现沈知夏的伤口对某种扫描光有异常反应。

## 预期风险点

- 受伤角色突然做高强度动作。
- 道具归属错乱。
- 地点瞬移。

## 评价指标

重点看人物状态一致性、地点一致性、道具归属一致性。
