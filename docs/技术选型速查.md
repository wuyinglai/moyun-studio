# 墨韵 - 技术选型速查

> 本文档是 `技术选型与依赖.md` 的精简版本，只保留当前实际使用和必须遵守的规则。
> 版本号以 `requirements.txt` 和 `package.json` 为准。

---

## 一、后端技术栈

| 库 | 用途 | 强制要求 |
|----|------|----------|
| **FastAPI** | Web 框架 | 所有 API 端点必须用 FastAPI + `async def` 定义 |
| **LiteLLM** | 统一 LLM 调用 | 禁止直接用 `openai` 库调用 LLM |
| **aiofiles** | 异步文件读写 | 禁止用同步 `open()` |
| **pydantic-settings** | 配置管理 | 禁止用 `os.getenv()` |
| **Jinja2** | Prompt 模板引擎 | 禁止硬编码 Prompt 在代码里 |
| **tiktoken** | Token 计数 | 调用 LLM 前必须检查 token 数 |
| **tenacity** | 重试机制 | 所有 LLM 调用必须用 tenacity 包装 |
| **watchdog** | 文件系统监听 | 可选（可用 watchfiles 替代） |
| **python-frontmatter** | Markdown 元数据 | `.md` 文件元数据必须用 frontmatter 格式 |
| **uvicorn** | ASGI 服务器 | 开发用 `--reload`，生产用 gunicorn |

## 三、禁止引入

| 库 | 原因 |
|----|------|
| **LangChain** | 太重，不需要链和记忆 |
| **LlamaIndex** | 非 RAG 场景 |
| **Celery** | 单机部署，不需要分布式任务队列 |
| **SQLAlchemy** | 文件存储，不需要 ORM |
| **Flask / Django** | 已用 FastAPI |

## 四、架构原则

1. **后端五层**：`api/` → `application/` → `domain/` → `infrastructure/` + `schemas/`，上层依赖下层
2. **Prompt 独立**：所有 Prompt 存于 `workspace/prompts/`，禁止硬编码
3. **响应格式统一**：`{"success": bool, "data": ..., "message": "...", "error": ...}`
4. **SSE 事件**：内部用 colon 风格（如 `file:updated`），网络传输时 `:` 自动替换为 `-`，前端按转换后名称监听
5. **文件存储**：所有数据以文件形式存于 `workspace/projects/`
