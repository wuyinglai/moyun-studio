Prompt 分类体系

🌐 全局 Prompt
所有项目可用，写得好就长期保留
• 情节逻辑检查
• 文风润色
• 角色一致性
• 设定偏移检测
📚 按类型 Prompt
特定题材的专属 Prompt
• 言情小说: 情感描写
• 科幻小说: 世界观构建
• 悬疑小说: 伏笔设计
📄 项目 Prompt
仅当前项目的自定义 Prompt
• 本书专用写作指引
• 特定角色语气模板
• 用户自己写的小众需求

核心交互

① 浏览 Prompt 库
右侧面板「提示词」Tab 变成 Prompt 库，三级分类切换
② 应用到文章
选中 Prompt → 点「应用」→ AI 根据 Prompt 修改当前文件内容 → 流式出结果
③ 拖拽归类
写好一个 Prompt 可以拖到全局/类型/项目下，自由归类
④ 迭代优化
用过之后觉得效果一般？编辑 Prompt 内容，保存即更新，越用越好用
