# Case 02: Item Ownership

## 上文摘要

林澈从旧港站保险箱里取出银色芯片，并把它放进贴身内袋。沈知夏只看过芯片外壳上的编号，没有碰过它。追兵只知道芯片存在，但没有见到实物。

## 事实块

- 人物状态：林澈和沈知夏正在被追兵盘问。
- 道具归属：银色芯片在林澈贴身内袋中。
- 地点限制：旧港站附近的隐蔽通道或盘查点。
- 时间线：芯片尚未被读取或解码。
- 信息边界：追兵不知道芯片的具体编号。

## 禁止改变项

- 不能让敌人突然拿到芯片。
- 不能让沈知夏突然从口袋里拿出芯片。
- 不能直接揭示芯片完整用途。
- 不能让追兵知道具体编号。

## 本场目标

追兵设下诱导盘问，试图从两人的反应判断芯片是否在林澈身上。林澈必须隐藏芯片归属，同时暴露一个新的危险线索。

## 预期风险点

- 道具突然换持有人。
- 芯片被提前破解。
- 敌人知道不该知道的信息。

## 评价指标

重点看道具归属一致性、禁止事项遵守、伏笔处理。
