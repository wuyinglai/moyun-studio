# Variant D：完整约束 + 禁止模板词 + 降低 AI 腔

## 目标

最大限度降低低质量输出和 AI 腔。

## Prompt Patch

```
本场正文生成要求：

一、基础长度
- 目标长度：1000-1500 字；
- 最低不得少于 900 字；
- 至少 6 个自然段；
- 禁止用摘要、说明、提纲替代正文。

二、场景结构
- 至少包含 3 个行动段落；
- 每个行动段落必须包含：角色行动、外部反馈、局势变化；
- 不要连续两段只写心理活动；
- 不要连续两段只写背景解释。

三、冲突推进
本场必须推进一个具体冲突：
- 敌人施压；
- 资源减少；
- 时间压力增加；
- 关系恶化；
- 新秘密暴露；
- 主角被迫选择；
- 计划出现偏差。

四、人物表现
- 通过动作、对话、选择表现人物；
- 少用抽象形容；
- 少用总结性评价；
- 不要替读者解释人物性格。

五、结尾要求
- 结尾留下下一场可执行动作；
- 结尾应包含未解决的压力或选择；
- 不要完全解决本场全部矛盾。

六、禁止输出
严禁出现以下内容：
- "以下是"
- "本章主要讲述"
- "总结来说"
- "最近5章摘要"
- "系统自动维护"
- "占位"
- "TODO"
- 模板占位符
- Markdown 表格
- JSON
- 大纲
- 说明文字
- 系统提示

七、风格要求
- 直接写正文；
- 使用具体动作和感官细节；
- 保持节奏紧凑；
- 避免 AI 腔；
- 避免空泛抒情。
```

## 预期改善

1. 降低 template_leak
2. 降低 AI 腔
3. 增强文本可读性
4. 增强情节推进密度

## 潜在风险

1. 约束较重
2. 可能导致模型过度遵循格式
3. 可能牺牲自然感
4. 可能不适合所有题材
5. 可能增加 token 成本

## 适用判断

如果 Variant D 分数高但文本僵硬，应回退到 Variant C 或把部分禁止项拆成后处理检测。
