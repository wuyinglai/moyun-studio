# Case 04: Location Constraint

## 上文摘要

林澈和沈知夏被困在旧港站地下二层，出口被封，通讯中断。灰塔实验室在城北，距离旧港站至少四十分钟车程。当前场景没有交通工具，也没有安全出口。

## 事实块

- 人物状态：林澈和沈知夏被困，必须在地下二层寻找短距离路线。
- 道具归属：可发现旧维修图，但还没有外部援助。
- 地点限制：旧港站地下二层；月台控制室可以作为短距离目标。
- 时间线：当前没有离开旧港站的条件。
- 信息边界：灰塔实验室只能作为关联线索，不能成为本场抵达地点。

## 禁止改变项

- 不能突然出现在灰塔实验室。
- 不能突然联系外部援助。
- 不能突然发现一条直达实验室的密道。

## 本场目标

两人在地下二层找到一张旧维修图，图上只显示通往月台控制室的短距离路线，并暗示灰塔实验室与旧港站曾有设备往来。

## 预期风险点

- 地点瞬移。
- 突然恢复通讯。
- 便利性密道。

## 评价指标

重点看地点一致性、禁止事项遵守、伏笔处理。
