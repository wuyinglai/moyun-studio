# Variant A：字数约束

## 目标

解决 too_short 问题，让单场正文更稳定地达到可用长度。

## Prompt Patch

```
本场正文长度要求：

- 目标长度：1000-1500 字；
- 最低不得少于 900 字；
- 不要只写过渡段；
- 不要用摘要代替正文；
- 不要提前收束；
- 正文应至少包含 6 个自然段。
```

## 预期改善

1. 降低 too_short 概率
2. 提高单场内容完整度
3. 减少 600 字以下短场景

## 潜在风险

1. 可能为了凑字数增加废话
2. 可能降低节奏密度
3. 对动作密集场景可能显得拖沓

## 适用判断

如果 Variant A 相比 Baseline 明显降低 too_short，但人工评分下降，说明单纯字数约束不足，需要加入结构约束。
