# 墨韵 - AI 小说创作助手 产品说明

## 一、产品概述

### 1.1 产品名称
墨韵 - AI 小说创作助手

### 1.2 产品定位
一款面向中文小说创作者的AI辅助写作工具，通过AI技术帮助用户从零开始创作完整的小说作品。支持从项目创建、大纲生成、章节写作到内容润色的全流程自动化。

### 1.3 核心价值
- **零门槛创作**：用户只需选择创作参数，AI自动生成书名、大纲、章节内容
- **灵活控制**：支持L1半自动/L2连续两种自动化等级
- **实时协作**：通过SSE实时显示AI生成过程，随时干预调整
- **Prompt可视化**：显示发送给AI的完整Prompt，透明可控

### 1.4 目标用户
- 网文作者：快速产出内容，提高创作效率
- 写作爱好者：降低创作门槛，体验AI辅助写作
- 内容创作者：批量生成小说内容

## 二、界面布局

### 2.1 整体结构
采用经典的三栏布局：
- **左侧边栏**（约240px）：文件树，显示项目文件结构
- **中间主区域**（flex:1）：编辑器+聊天区，核心工作区
- **右侧面板**（约320px，可拖拽调整）：Prompt/自动化/执行面板

### 2.2 顶部工具栏
高度约56px，从左到右依次为：
1. **Logo区域**：墨韵图标+文字
2. **项目名称**：显示当前打开的项目名（可编辑）
3. **LLM连接状态**：状态点+文字（"已连接"/"未连接"），可点击打开设置
4. **LLM调用中**：调用时显示加载动画+当前操作名称
5. **Thinking开关**：快捷开关，控制AI思考模式
6. **操作按钮**：
   - 打开项目（次要按钮）
   - 新建项目（主要按钮，蓝色高亮）
   - 设置（图标按钮）

**通知区域**：显示在顶部工具栏中间，用于操作成功/失败提示

### 2.3 左侧文件树
- 标题栏：显示"文件"+ 刷新按钮
- 树形结构：支持展开/折叠
- 文件类型图标：区分文件夹和文件
- 空状态：未打开项目时显示"选择或创建项目"
- 文件夹用途：
  - `chapters/` - 章节文件（卷/章/节三级结构）
    - `vol-{序号}/` - 卷目录
      - `vol-meta.json` - 卷元数据
      - `ch-{序号}/` - 章目录
        - `ch-meta.json` - 章元数据（含memory）
        - `sec-{序号}.md` - 节内容文件
  - `characters/` - 角色档案（JSON格式）
    - `{角色ID}.json` - 角色档案
  - `materials/extracted/` - 提取的信息
    - `plots/` - 情节提取
    - `scenes/` - 场景提取
    - `summaries/` - 摘要提取
    - `{自定义类型}/` - 用户自定义提取类型
  - `backup/` - 版本快照
  - `prompts/` - Prompt模板（可复用）
    - `generate/` - 生成类模板
    - `extract/` - 提取类模板
    - `transform/` - 转换类模板

### 2.4 中间编辑器区
- **标签页栏**：多文件标签，支持切换和关闭
- **工具栏**：
  - 重写本文件（主要按钮，蓝色）
  - 写下一部分
  - 前进/后退
  - 停止（红色，任务进行中显示）
- **编辑区**：
  - 占位符：未打开文件时显示"打开左侧文件开始编辑..."
  - 内容区：contenteditable，支持富文本编辑
  - 状态提示：右上角显示保存状态
- **聊天区**：
  - 消息列表：显示对话历史
  - 输入框：多行文本输入
  - 发送按钮：纸飞机图标

### 2.5 右侧面板
单一Tab标签页："Prompt & 执行"

1. **Prompt面板**（默认显示）：
   - 标题："发送给LLM的Prompt"
   - 内容区：可编辑的Prompt文本
   - 引用文件：超级链接展示，点击打开对应文件

2. **执行面板**：
   - 状态指示：空闲 / 运行中
   - LLM工作堆栈：所有LLM任务列表
   - 任务卡片：任务名、描述、状态、进度条
   - 执行日志：实时日志输出

### 2.6 模态框
- **新建项目模态框**：
  - 创作参数选择：题材/基调/背景/主题/写作风格（按钮组，单选）
  - 作品规模：5万/10万/15万/20万字
  - 作者名、项目路径（可选）
  - 点击"创建项目"后进入三阶段引导流程

- **打开项目模态框**：
  - 项目列表：显示项目名、创建时间、完成度
  - 操作：打开、删除

- **设置模态框**：
  - 主题选择：深邃夜紫/墨绿护眼/经典炭灰
  - 自动化等级：L1半自动/L2连续
  - LLM配置：API地址、API Key、模型选择
  - Thinking模式开关
  - 测试连接、获取模型按钮

## 三、核心功能流程

### 3.1 新建项目流程
```
1. 点击"新建"按钮
2. 弹出创建项目模态框
3. 选择创作参数（题材/基调/背景/主题/风格）
4. 选择作品规模（5万/10万/15万/20万字）
5. 点击"创建项目"
6. 进入三阶段引导流程：
   - 阶段1：AI生成书名+创意 → 用户确认/编辑
   - 阶段2：AI生成大纲（含卷/章/节结构） → 用户确认/编辑
   - 阶段3：自动生成目录结构，开始写作
7. 完成创建，打开项目
```

**目录生成规则**：
- 根据作品规模计算总节数：总字数 / 1800（每节约1800字）
- 章序号全局连续，每章固定4节
- 自动划分卷（通常8-15章一卷）
- 生成的三级目录结构：
  ```
  chapters/
  ├── vol-01/
  │   ├── vol-meta.json
  │   ├── ch-001/
  │   │   ├── ch-meta.json
  │   │   ├── sec-001.md
  │   │   ├── sec-002.md
  │   │   ├── sec-003.md
  │   │   └── sec-004.md
  │   └── ch-002/
  └── vol-02/
  ```
- 同时生成 `characters/`、`materials/extracted/`、`backup/` 目录

### 3.2 编辑器操作流程
```
1. 从文件树点击打开文件
2. 在编辑器中查看/编辑内容
3. 点击工具栏按钮触发AI操作：
   - 重写本文件：AI重新生成整个文件内容
   - 写下一部分：AI在文件末尾续写
4. 右侧面板实时显示Prompt
5. 执行面板显示任务进度
6. 完成后自动更新文件内容
```

### 3.3 AI对话流程
```
1. 在底部聊天输入框输入需求
2. 点击发送或按Enter
3. 消息显示在聊天区（用户消息靠右）
4. AI开始处理，显示"LLM调用中"
5. AI回复流式显示在聊天区（AI消息靠左）
6. 完成后隐藏"LLM调用中"状态
```

### 3.4 自动化等级
- **L1 半自动**：默认模式，每步操作需要用户确认后，AI才执行下一步
- **L2 连续**：AI自动连续执行，无需等待用户确认

## 九、典型用户场景

### 场景1：新手创作
1. 用户点击"新建项目"
2. 选择"科幻"题材、"史诗"基调、"星际"背景
3. 选择10万字规模
4. AI自动生成书名《星际迷途》
5. 用户确认后，AI生成大纲
6. 用户编辑大纲，调整章节
7. AI根据大纲逐章生成内容
8. 用户查看、修改、润色

### 场景2：续写优化
1. 用户打开已有项目
2. 打开某个章节文件
3. 编辑或定位到需要续写的位置
4. 点击"写下一部分"
5. AI从当前位置续写内容
6. 用户查看、修改、保存

### 场景3：批量生成
1. 用户设置自动化等级为L2连续
2. AI自动按大纲生成所有章节
3. 用户只需监控进度
4. 完成后统一审阅修改

### 12.2 SSE事件类型
| 事件 | 触发时机 | 处理逻辑 |
|------|----------|----------|
| `generation` | AI生成内容 | 编辑器内逐字/逐段显示 |
| `file-created` | 新文件创建 | 刷新文件树 |
| `file-updated` | 文件内容更新 | 更新编辑器内容 |
| `file-renamed` | 文件重命名 | 刷新文件树，更新标签页 |
| `directory-created` | 目录创建 | 刷新文件树 |
| `task` | 任务状态变化 | 更新任务卡片 |
| `queue` | 队列变化 | 刷新堆栈列表 |
| `llm-status` | LLM状态变化 | 更新状态灯 |
| `thinking` | AI思考中 | 显示"AI正在思考..." |
| `error` | 错误 | 显示错误横幅 |
| `done` | 任务完成 | 停止加载动画 |

### 12.4 新增质量保障功能

#### 文风指南 (style-guide.md)
- 定义小说的文风要求，指导 AI 生成符合期望的文字风格
- 包含语言风格、句子节奏、描写密度、语言特点等要素
- 支持用户自定义文风示例

#### 故事全局状态 (story-state.md)
- 记录小说的全局状态，包括主角当前状态、势力变化、伏笔追踪等
- 每次生成新章节后自动更新
- 包含主线/支线进度追踪

#### 近期上下文 (recent-context.md)
- 存储最近5章的摘要
- 用于在生成章节时提供近期情节上下文
- 每次生成章节后自动追加

#### 用户反馈 (feedback/)
- 用户提交反馈时创建反馈记录
- 保存到章节目录下 `feedback/` 子目录
- 支持查看和管理反馈记录

#### 修改日志 (revision-log/)
- AI重写或用户修改时创建修改日志
- 保存到章节目录下 `revision-log/` 子目录
- 支持查看修改历史和版本对比
