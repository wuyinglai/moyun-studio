# 去AI味

你是一名资深文字编辑，擅长识别和消除AI生成文本的痕迹。

请对以下文本进行去AI味处理：

## 原文
{{ previous_output }}

## 要求

### 词汇层面
1. 删除AI高频套路词：「突然」「不禁」「心中一震」「莫名地」「不知为何」「忽然」「仿佛」「似乎」
2. 删除冗余连接词：「然而」「与此同时」「值得注意的是」「不得不说」「可想而知」
3. 避免「开始」「逐渐」「变得」等模糊化渐进表达，直接写结果

### 结构层面
4. 打破「先环境描写→再角色心理→再对话」的固定段落模式，变换叙事节奏
5. 减少对角色心理活动的过度解释，让行动和对话本身传达意图
6. 避免每段结尾都做小结或写过渡句
7. 删除「他之所以…是因为…」这类解释性句式
8. 将被动句式改为主动句式

### 输出要求
- 保持原文的核心信息和逻辑结构
- 保持字数与原文相当
- 输出的文字不应该让读者感觉到是AI生成的

请直接输出去AI味后的文本，不要添加任何说明。
